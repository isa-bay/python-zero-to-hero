## Типы данных в Python

### Основы типов данных
#### Что такое тип данных?
Тип данных определяет:
- Какие значения может принимать объект (диапазон)
- Какие операции можно выполнять с объектом (интерфейс)
- Как объект хранится в памяти (структура)
- Как объект ведет себя при взаимодействии (семантика)

В Python **всё является объектом**, и каждый объект имеет тип, который нельзя изменить после создания (хотя переменная может ссылаться на объекты разных типов)

#### Система типов Python
```python
# У каждого объекта есть тип
print(type(42))           # <class 'int'>
print(type("hello"))      # <class 'str'>
print(type([1, 2, 3]))    # <class 'list'>
print(type(type(42)))     # <class 'type'> - метакласс

# Тип объекта можно проверить
x = 42
print(isinstance(x, int))     # True
print(isinstance(x, object))  # True (всё наследники object)
print(issubclass(bool, int))  # True (bool это подтип int)
```

#### Три кита системы типов Python
**1. Сильная типизация (Strong typing)**
Python не выполняет неявные преобразования, которые могут привести к потере данных или ошибкам
```python
# Сильная типизация - ошибка вместо неявного преобразования
print("42" + 10)  # TypeError: can only concatenate str (not "int") to str

# В слабо типизированных языках (JavaScript) это сработало бы:
# "42" + 10 = "4210" (конкатенация) или 52 (сложение) - зависит от контекста

# Нужно явное преобразование
print(int("42") + 10)  # 52
print("42" + str(10))  # "4210"
```

**2. Динамическая типизация (Dynamic typing)**
Тип связан со значением, а не с переменной
```python
# Переменная может ссылаться на объекты разных типов
value = 42          # int
print(type(value))

value = "теперь строка"  # str - тот же ярлык, другой объект
print(type(value))

value = [1, 2, 3]   # list
print(type(value))

# В статически типизированных языках (Java, C++) переменная раз и навсегда привязана к типу
# int value = 42;    // только int
# value = "string";  // Ошибка компиляции!
```

**3. Утиная типизация (Duck typing)**
"Если это ходит как утка и крякает как утка, значит это утка" — важность представляет поведение, а не формальный тип
```python
def process_iterable(items):
    """Функция работает с ЛЮБЫМ итерируемым объектом"""
    return [item.upper() if hasattr(item, 'upper') else item for item in items]

# Работает со списком
print(process_iterable(["a", "b", "c"]))  # ['A', 'B', 'C']

# Работает с кортежем
print(process_iterable(("x", "y", "z")))  # ['X', 'Y', 'Z']

# Работает с множеством
print(process_iterable({"hello", "world"}))  # ['HELLO', 'WORLD']

# Работает с генератором
print(process_iterable(range(3)))  # [0, 1, 2] (upper не применяется)

# Работает с пользовательским классом, если он итерируемый
class MyCollection:
    def __init__(self, data):
        self.data = data
    def __iter__(self):
        return iter(self.data)

obj = MyCollection(["test", "data"])
print(process_iterable(obj))  # ['TEST', 'DATA']
```

#### Абстрактные базовые классы (ABC)
Python предоставляет систему абстрактных базовых классов для формализации интерфейсов
```python
from collections.abc import (
    Container, Hashable, Iterable, Iterator, 
    Sequence, MutableSequence, Mapping, MutableMapping,
    Set, MutableSet, Callable
)

# Проверка на соответствие интерфейсу, а не конкретному типу
def check_interfaces(obj):
    print(f"Container (поддерживает 'in'): {isinstance(obj, Container)}")
    print(f"Iterable (можно итерировать): {isinstance(obj, Iterable)}")
    print(f"Sequence (упорядоченная коллекция): {isinstance(obj, Sequence)}")
    print(f"Hashable (можно использовать как ключ): {isinstance(obj, Hashable)}")
    print(f"Callable (можно вызвать): {isinstance(obj, Callable)}")

print("=== Список ===")
check_interfaces([1, 2, 3])

print("\n=== Кортеж ===")
check_interfaces((1, 2, 3))

print("\n=== Множество ===")
check_interfaces({1, 2, 3})

print("\n=== Функция ===")
check_interfaces(lambda x: x)

# Container: поддерживает 'in'
# Iterable: можно в for
# Sequence: есть длина и индексы
# Hashable: можно в set/dict ключ
```

### Числовые типы (Numeric Types)
#### int — целые числа произвольной точности
В Python нет ограничения на размер целого числа (кроме доступной памяти)
```python
# Создание int
a = 42               # десятичная система
b = 0b101010         # двоичная (42)
c = 0o52             # восьмеричная (42)
d = 0x2A             # шестнадцатеричная (42)
e = int("42")        # из строки
f = int(3.14)        # из float (отбрасывает дробную часть)

print(a, b, c, d)    # 42 42 42 42

# Произвольная точность
small = 42
large = 10**100      # 1 с 100 нулями
huge = 2**10000      # 2 в степени 10000 (огромное число)

print(f"large: {large}")
print(f"битов huge: {huge.bit_length()}")  # количество бит

# Особые методы
x = 255
print(x.bit_length())      # 8 (бит для представления)
print(x.to_bytes(2, 'big'))  # b'\x00\xff' (в байты)
print(int.from_bytes(b'\x00\xff', 'big'))  # 255 (из байт)
```

**Реализация int в CPython**
В CPython int — это массив "цифр" в системе счисления с основанием 2^30 (на 64-битных системах). Поэтому:
- Маленькие числа (до 2^30) хранятся быстро
- Большие числа требуют O(n) времени для операций
- Сложение/вычитание линейно от количества цифр
- Умножение использует алгоритмы Карацубы и FFT для больших чисел

#### float — числа с плавающей точкой
Реализуют стандарт IEEE 754 (double-precision, 64 бита)
```python
# Создание float
a = 3.14
b = .5               # 0.5
c = 1e-3             # 0.001 (научная нотация)
d = float("inf")     # бесконечность
e = float("nan")     # Not a Number
f = 1.2e3            # 1200.0

# Проблема точности
print(0.1 + 0.2)          # 0.30000000000000004 (не 0.3!)
print(0.1 + 0.2 == 0.3)   # False!

# Как сравнивать float правильно
def float_eq(a, b, eps=1e-10):
    return abs(a - b) < eps

print(float_eq(0.1 + 0.2, 0.3))  # True

# Специальные значения
import math
print(math.isinf(d))      # True
print(math.isnan(e))      # True
print(math.isfinite(a))   # True

# Особенности NaN
nan = float('nan')
print(nan == nan)         # False! NaN не равен самому себе
print(math.isnan(nan))    # True (правильная проверка)

# Инструменты для работы с float
print(round(3.14159, 2))          # 3.14
print(math.floor(3.9))            # 3
print(math.ceil(3.1))             # 4
print(math.trunc(3.9))            # 3 (отбрасывание дробной части)
print(format(0.1, '.20f'))        # 0.10000000000000000555 (реальное представление)
```

#### complex — комплексные числа
```python
# Создание комплексных чисел
c1 = 3 + 4j
c2 = complex(3, 4)    # то же самое
c3 = 5j               # чисто мнимое

# Доступ к частям
print(c1.real)        # 3.0 (вещественная часть)
print(c1.imag)        # 4.0 (мнимая часть)
print(c1.conjugate()) # (3-4j) (сопряженное)

# Операции
print(c1 + c2)        # (6+8j)
print(c1 * c2)        # (-7+24j) (формула: (a+bi)(c+di) = (ac-bd) + (ad+bc)i)

# Модуль и фаза
import cmath
print(abs(c1))                   # 5.0 (модуль)
print(cmath.phase(c1))            # 0.9272952180016122 (фаза в радианах)
print(cmath.polar(c1))            # (5.0, 0.9272952180016122) (полярные координаты)

# Из полярных обратно
print(cmath.rect(5, 0.927))       # (3.000+4.001j) (с небольшой погрешностью)
```

#### Дробные числа (Fraction) и Decimal
Для специальных случаев точных вычислений
```python
from fractions import Fraction
from decimal import Decimal, getcontext

# Fraction — точные рациональные числа
f1 = Fraction(1, 3)        # 1/3
f2 = Fraction(2, 6)        # автоматически сокращается до 1/3
print(f1 == f2)            # True
print(f1 * 3)              # 1 (точное значение!)
print(f1 + Fraction(1, 2)) # 5/6

# Decimal — десятичные числа с контролируемой точностью
getcontext().prec = 28     # устанавливаем точность (28 знаков)

d1 = Decimal('0.1')        # строка важна!
d2 = Decimal('0.2')
print(d1 + d2)             # 0.3 (точно!)
print(Decimal(0.1))        # 0.1000000000000000055511151231257827021181583404541015625 (из float!)

# Настройка контекста для Decimal
from decimal import localcontext

with localcontext() as ctx:
    ctx.prec = 50  # повышенная точность для этого блока
    result = Decimal('1') / Decimal('3')
    print(result)  # 0.3333333333333333333333333333
```

#### Правила "правдивости" (Truth Value Testing)
Любой объект в Python может быть интерпретирован как булев
```python
def check_truth(value):
    if value:
        print(f"{repr(value)} -> True")
    else:
        print(f"{repr(value)} -> False")

# False в булевом контексте:
check_truth(None)           # None -> False
check_truth(False)          # False -> False
check_truth(0)              # 0 -> False
check_truth(0.0)            # 0.0 -> False
check_truth(0j)             # 0j -> False
check_truth("")             # '' -> False
check_truth([])             # [] -> False
check_truth(())             # () -> False
check_truth({})             # {} -> False
check_truth(set())          # set() -> False
check_truth(range(0))       # range(0, 0) -> False

# Всё остальное True
check_truth(True)           # True -> True
check_truth(1)              # 1 -> True
check_truth(-1)             # -1 -> True
check_truth([0])            # [0] -> True
check_truth("False")        # 'False' -> True (непустая строка!)
check_truth(object())       # <object object at...> -> True
```

### Кастомизация булевой логики в классах
```python
class MyList:
    def __init__(self, items):
        self.items = items
    
    def __bool__(self):
        # Определяем, когда объект считается True/False
        return len(self.items) > 0
    
    def __len__(self):
        # fallback, если __bool__ не определен
        return len(self.items)

# __bool__ приоритетнее __len__
print(bool(MyList([])))        # False
print(bool(MyList([1, 2])))    # True

class AlwaysTrue:
    def __bool__(self):
        return True

print(bool(AlwaysTrue()))      # True (даже пустой)
```

#### Unicode и кодировки
```python
# Строки — это Unicode
text = "Привет, мир! 🌍"
print(len(text))          # 14 (символов, не байт!)

# Кодирование/декодирование
encoded = text.encode('utf-8')     # в байты
print(encoded)                     # b'\xd0\x9f...'
print(type(encoded))                # <class 'bytes'>

decoded = encoded.decode('utf-8')   # обратно в строку
print(decoded == text)              # True

# Разные кодировки
latin = "café".encode('latin-1')    # для западноевропейских
print(latin)

# Ошибки кодирования
try:
    "café".encode('ascii')          # 'é' нет в ascii
except UnicodeEncodeError as e:
    print(f"Ошибка: {e}")

# Стратегии обработки ошибок
print("café".encode('ascii', errors='ignore'))     # b'caf'
print("café".encode('ascii', errors='replace'))    # b'caf?'
print("café".encode('ascii', errors='xmlcharrefreplace'))  # b'caf&#233;'
```

#### Производительность строк
```python
import timeit

# ПЛОХО: конкатенация в цикле
def bad_concat(n):
    s = ""
    for i in range(n):
        s += str(i)    # создается новая строка на каждой итерации!
    return s

# ХОРОШО: join списка
def good_concat(n):
    parts = []
    for i in range(n):
        parts.append(str(i))
    return ''.join(parts)

# ЕЩЕ ЛУЧШЕ: генератор и join
def best_concat(n):
    return ''.join(str(i) for i in range(n))

# Сравнение времени
n = 10000
print(timeit.timeit(lambda: bad_concat(n), number=100))
print(timeit.timeit(lambda: good_concat(n), number=100))
print(timeit.timeit(lambda: best_concat(n), number=100))

# Форматирование строк (сравнение методов)
name, age = "Анна", 25

# %-formatting (старый стиль)
print("Имя: %s, возраст: %d" % (name, age))

# str.format()
print("Имя: {}, возраст: {}".format(name, age))
print("Имя: {name}, возраст: {age}".format(name=name, age=age))

# f-strings (Python 3.6+) - обычно самые быстрые
print(f"Имя: {name}, возраст: {age}")
print(f"2 + 2 = {2 + 2}")
print(f"Имя в верхнем: {name.upper()}")
```

### NoneType (None)
#### Природа None
`None` — это синглтон, обозначающий отсутствие значения
```python
# None — это единственный объект своего типа
a = None

print(a is b)          # True (один объект)
print(a is None)       # True (правильная проверка)

# Почему is, а не ==
class Bad:

        return True

bad = Bad()

print(bad is None)     # False (честно)
```

### Коллекции
#### Последовательности (Sequence Types)
**Списки (list)** - изменяемые, динамические массивы
```python
# Создание
empty = []
numbers = [1, 2, 3]
mixed = [1, "hello", 3.14, [1, 2]]
from_range = list(range(5))
from_string = list("hello")  # ['h', 'e', 'l', 'l', 'o']
comprehension = [x**2 for x in range(10)]

# Важные методы
lst = [1, 2, 3]
lst.append(4)           # [1, 2, 3, 4] (O(1) амортизировано)
lst.extend([5, 6])       # [1, 2, 3, 4, 5, 6] (O(k))
lst.insert(0, 0)         # [0, 1, 2, 3, 4, 5, 6] (O(n))
lst.pop()                # 6 (удаляет последний, O(1))
lst.pop(0)               # 0 (удаляет первый, O(n))
lst.remove(3)            # удаляет первое вхождение 3 (O(n))
lst.index(4)             # поиск индекса (O(n))
lst.count(2)             # количество вхождений (O(n))
lst.sort()               # сортировка на месте (O(n log n))
lst.reverse()            # разворот на месте (O(n))

# Срезы (slicing) — создают новые списки
lst = [0, 1, 2, 3, 4, 5]
print(lst[1:4])          # [1, 2, 3]
print(lst[:3])           # [0, 1, 2]
print(lst[3:])           # [3, 4, 5]
print(lst[::2])          # [0, 2, 4]
print(lst[::-1])         # [5, 4, 3, 2, 1, 0] (разворот)

# Присваивание срезу (изменение части списка)
lst[1:3] = [10, 20]      # [0, 10, 20, 3, 4, 5]
lst[1:3] = [100]         # [0, 100, 3, 4, 5] (замена двух элементов одним)
lst[1:1] = [1, 2]        # вставка без удаления: [0, 1, 2, 100, 3, 4, 5]

# Реализация list в CPython
import sys

empty = []
one = [1]
ten = list(range(10))
hundred = list(range(100))

print(f"Пустой список: {sys.getsizeof(empty)} байт")
print(f"1 элемент: {sys.getsizeof(one)} байт")
print(f"10 элементов: {sys.getsizeof(ten)} байт")
print(f"100 элементов: {sys.getsizeof(hundred)} байт")

# Over-allocation (выделение с запасом)
import sys

lst = []
for i in range(10):
    lst.append(i)
    print(f"len={len(lst)}, size={sys.getsizeof(lst)} байт")
# Размер растет не на 1 элемент, а с запасом
```

**Кортежи (tuple)** - неизменяемые последовательности
```python
# Создание
empty = ()
single = (1,)          # запятая обязательна!
tuple1 = (1, 2, 3)
tuple2 = 1, 2, 3       # без скобок (упаковка кортежа)
from_list = tuple([1, 2, 3])
from_string = tuple("abc")  # ('a', 'b', 'c')

# Особенности
t = (1, [2, 3], 4)
# t[0] = 10           # TypeError! кортеж неизменяем
t[1].append(4)        # OK! (список внутри изменяемый)
print(t)              # (1, [2, 3, 4], 4)

# Распаковка кортежей
point = (10, 20)
x, y = point          # распаковка
print(x, y)           # 10 20

# Именованные кортежи (namedtuple)
from collections import namedtuple

Point = namedtuple('Point', ['x', 'y'])
```

#### Таблица характеристик
| Тип | Изменяемый | Упорядоченный | Индексируемый | Хешируемый | Дубликаты | Когда использовать |
|-----|:---------:|:-------------:|:-------------:|:----------:|:---------:|-------------------|
| `list` | ✅ | ✅ | ✅ | ❌ | ✅ | Упорядоченные данные, частые изменения, доступ по индексу |
| `tuple` | ❌ | ✅ | ✅ | ✅* | ✅ | Фиксированные данные, ключи dict, защита от изменений |

| `str` | ❌ | ✅ | ✅ | ❌ | ✅ | Текст, неизменяемые последовательности символов |

**Кортеж хешируем, если все его элементы хешируемы*
***Словари сохраняют порядок вставки с Python 3.7*

#### Руководство по выбору
```python
# Сценарии использования

# 1. Нужен быстрый поиск по значению -> set
emails = set()
# добавить email: O(1)
# проверить есть ли: O(1)

# 2. Нужен доступ по ключу -> dict
user_by_id = {}
user = user_by_id[42]  # O(1)

# 3. Нужен порядок и индексы -> list
queue = []
queue.append(task)   # O(1) в конец
first = queue.pop(0) # O(n) плохо! Используйте collections.deque

# 4. Данные не будут меняться -> tuple
DEFAULT_CONFIG = ('localhost', 8080, True)

# 5. Нужна очередь с двух концов -> deque
from collections import deque
dq = deque()
dq.appendleft(x)     # O(1)
dq.pop()             # O(1)

# 6. Нужен счетчик -> Counter
from collections import Counter
cnt = Counter("hello")
print(cnt['l'])      # 2

# 7. Нужен словарь со значениями по умолчанию -> defaultdict
from collections import defaultdict
dd = defaultdict(list)
dd['key'].append(1)  # не нужно проверять наличие
```

### Частые ошибки

#### 1. Использование изменяемых объектов как умолчаний
```python
# ОШИБКА
def add_item(item, lst=[]):
    lst.append(item)
    return lst

print(add_item(1))  # [1]
print(add_item(2))  # [1, 2] - тот же список!

# ПРАВИЛЬНО
def add_item(item, lst=None):
    if lst is None:
        lst = []
    lst.append(item)
    return lst
```

#### 2. Путаница с изменяемостью
```python
# ОШИБКА: думаем, что кортеж защитит содержимое
t = ([1, 2], [3, 4])
t[0].append(5)      # Работает! Кортеж неизменяем, но списки внутри - да
print(t)            # ([1, 2, 5], [3, 4])

# ОШИБКА: изменение во время итерации
lst = [1, 2, 3, 4, 5]
for x in lst:
    if x % 2 == 0:
        lst.remove(x)  # Пропустит элементы!
print(lst)          # [1, 3, 5]? Не всегда!

# ПРАВИЛЬНО: создавать новый список
lst = [x for x in lst if x % 2 != 0]
```

#### 3. Сравнение float
```python
# ОШИБКА
if 0.1 + 0.2 == 0.3:  # False!
    print("равно")

# ПРАВИЛЬНО
epsilon = 1e-10
if abs((0.1 + 0.2) - 0.3) < epsilon:
    print("примерно равно")

# Или использовать Decimal
from decimal import Decimal
if Decimal('0.1') + Decimal('0.2') == Decimal('0.3'):
    print("точно равно")
```

#### 4. Копирование vs ссылки
```python
# ОШИБКА: поверхностное копирование
original = [[1, 2], [3, 4]]
shallow = original.copy()
shallow[0][0] = 99
print(original)  # [[99, 2], [3, 4]] - изменилось!

# ПРАВИЛЬНО: глубокое копирование
import copy
original = [[1, 2], [3, 4]]
deep = copy.deepcopy(original)
deep[0][0] = 99
print(original)  # [[1, 2], [3, 4]] - не изменилось
```

#### 5. Проверка на None
```python
# ОШИБКА
if value == None:  # __eq__ может быть переопределен
    pass

# ПРАВИЛЬНО
if value is None:  # всегда безопасно
    pass
```

#### 6. Путаница с {} и set()
```python
# ОШИБКА
empty_set = {}  # Это словарь!
print(type(empty_set))  # <class 'dict'>

# ПРАВИЛЬНО
empty_set = set()
print(type(empty_set))  # <class 'set'>

# Но с элементами работает
non_empty_set = {1, 2, 3}  # Это множество!
```

#### 7. Изменение словаря во время итерации
```python
# ОШИБКА
d = {'a': 1, 'b': 2, 'c': 3}
for k in d:
    if k == 'b':
        del d[k]  # RuntimeError!

# ПРАВИЛЬНО: итерироваться по копии ключей
for k in list(d.keys()):
    if k == 'b':
        del d[k]

# ИЛИ создать новый словарь
d = {k: v for k, v in d.items() if k != 'b'}
```

### Частые вопросы и ключевые выводы
#### FAQ
**В: Почему строки неизменяемы?**
**О:** Для безопасности (строки часто используются как ключи dict), производительности (можно кешировать хеш) и потокобезопасности. Неизменяемость позволяет интернировать строки и использовать их в множествах.

**В: Что быстрее — список или кортеж?**
**О:** Кортеж немного быстрее при создании и занимает меньше памяти. Доступ по индексу одинаков. Но разница обычно не критична. Главное — семантика: кортеж для фиксированных данных, список для изменяемых.

**В: Почему dict сохраняет порядок?**
**О:** С Python 3.6 как деталь реализации компактного представления, с 3.7 — гарантия языка. Это позволило уменьшить память на 20-25% и сохранить порядок вставки.

**В: Когда использовать set вместо list?**
**О:** Когда нужна уникальность элементов и/или быстрая проверка на вхождение (`in`). Для 10,000 элементов set может быть в сотни раз быстрее list.

**В: Что такое хешируемость?**
**О:** Объект хешируем, если у него есть метод `__hash__()`, который возвращает целое число, не меняющееся за время жизни объекта, и он сравним (`__eq__`). Хешируемые объекты можно использовать как ключи dict и элементы set.

**В: Как выбрать между int и float?**
**О:** Используйте int для счётчиков, индексов, дискретных значений. Используйте float для измерений, непрерывных величин. Для финансов всегда Decimal.
