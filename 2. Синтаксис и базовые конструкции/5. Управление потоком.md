## Что такое управление потоком?

**Управление потоком (control flow)** определяет порядок выполнения инструкций в программе. В Python, как и в других языках, есть три основных типа управления потоком
1. **Последовательное выполнение** — инструкции выполняются одна за другой
2. **Ветвление (условные операторы)** — выбор пути выполнения на основе условий
3. **Циклы (итерация)** — повторение блока кода

```python
# 1. Последовательное выполнение
x = 5
y = 10
z = x + y
print(z)  # 15

# 2. Ветвление
if z > 10:
    print("z больше 10")
else:
    print("z не больше 10")

# 3. Циклы
for i in range(3):
    print(f"Итерация {i}")
```

## Блоки кода и отступы
### Отступы как синтаксис
В Python блоки кода определяются **отступами** (обычно 4 пробела). Это уникальная особенность языка — в большинстве других языков используются фигурные скобки `{}`
```python
# Правильные отступы
if True:
    print("Это в блоке if")
    print("Тоже в блоке if")
print("Уже вне блока if")

# Сколько пробелов? Обычно 4
if True:
    print("4 пробела")
  print("2 пробела")  # SyntaxError! Несоответствие отступов

# Смешивать табуляцию и пробелы нельзя!
# Python 3 запрещает смешивание
```

### Почему отступы?
```python
# Визуальная структура кода совпадает с логической
def calculate(a, b, operation):
    if operation == "add":
        result = a + b
        print(f"Сложение: {result}")
        return result
    elif operation == "sub":
        result = a - b
        print(f"Вычитание: {result}")
        return result
    else:
        print("Неизвестная операция")
        return None

# Визуально сразу видно вложенность
```

### Правила отступов

## pass — заглушка для пустых блоков
`pass` — это оператор-заглушка, который ничего не делает. Используется, когда синтаксически требуется блок кода, но логически он пуст
```python
# Пустая функция
def not_implemented_yet():
    pass  # TODO: реализовать позже

# Пустой класс
class MyException(Exception):
    pass  # достаточно имени, поведение наследуется

# Пустой блок условия
if condition:
    pass  # пока ничего не делаем
else:
    print("Условие не выполнено")

# Пустой цикл (ожидание события)
while not event_occurred:
    pass  # активное ожидание (плохо, лучше time.sleep)

# В обработке исключений
try:
    dangerous_operation()
except SpecificError:
    pass  # сознательно игнорируем (осторожно!)
```

### Альтернативы pass
```python
# Многоточие (ellipsis) тоже работает
def func():
    ...  # то же самое, что pass

# Docstring тоже подходит
def func():
    """TODO: реализовать позже"""
    # тело функции может быть пустым, если есть docstring

# Но pass наиболее явный
```

## Сравнение с другими языками (блоки {})
### Python vs C/Java/JavaScript
```python
# Python — отступы
if (x > 0) {
    print("Положительное")
    print("x =", x)
}

# Scala/Java/JavaScript — фигурные скобки
if (x > 0) {
    System.out.println("Положительное");
    System.out.println("x = " + x);
}

# Python — двоеточие + отступ
if x > 0:
    print("Положительное")
    print("x =", x)
```

### Плюсы и минусы отступов

| Аспект | Отступы (Python) | Скобки (Scala/Java) |
|--------|------------------|------------------|
| Читаемость | ✅ Код всегда правильно отформатирован | ❌ Можно написать нечитаемо |
| Ошибки | ❌ Ошибка при смешивании табуляции/пробелов | ✅ Скобки легко автоматически расставить |
| Гибкость | ❌ Нельзя сжать в одну строку | ✅ Можно писать в одну строку |
| Начинающие | ✅ Учат правильно форматировать | ❌ Могут игнорировать форматирование |

### Guard Clauses (ранний выход)
```python
# Плохо: глубокая вложенность
def process_user(user):
    if user:
        if user.get('verified'):
            if user.get('age', 0) >= 18:
                if user.get('premium'):
                    return "Премиум доступ"
                else:
                    return "Базовый доступ"
            else:
                return "Доступ запрещен: возраст"
        else:
            return "Требуется верификация"
    return "Нет пользователя"

# Хорошо: guard clauses
def process_user(user):
    if not user:
        return "Нет пользователя"
    
    if not user.get('verified'):
        return "Требуется верификация"
    
    if user.get('age', 0) < 18:
        return "Доступ запрещен: возраст"
    
    if user.get('premium'):
        return "Премиум доступ"
    
    return "Базовый доступ"
```

## Сравнение цепочек условий
В Python можно строить цепочки сравнений, что соответствует математической записи
```python
# Математическая запись: 1 < x < 5
x = 3
print(1 < x < 5)        # True

# Это эквивалентно, но x вычисляется один раз:
print(1 < x and x < 5)  # True

# Можно любой длины
print(1 < 2 < 3 < 4 < 5)           # True
print(1 < 2 > 1 < 5 > 3)           # True

# С разными операторами
print(5 == 5 != 3)                 # True
print(5 > 4 >= 4 < 10)             # True

# Важно: каждый операнд вычисляется только один раз
def get_value():
    print("Вычисляется!")
    return 5

print(1 < get_value() < 10)  # "Вычисляется!" один раз
print(1 < get_value() and get_value() < 10)  # два раза!

# Практический пример
def is_between(value, low, high):
    return low <= value <= high

print(is_between(5, 1, 10))   # True
print(is_between(15, 1, 10))  # False

# Проверка на вхождение в диапазон
```

## Циклы

### while
Цикл `while` выполняется, пока условие истинно
```python
# Базовый while
count = 0
while count < 5:
    print(f"count = {count}")
    count += 1

# Бесконечный цикл (осторожно!)
# while True:
#     print("Бесконечность")

    num += 1
    if num % 2 == 0:
        continue  # четные пропускаем
    print(f"Нечетное: {num}")

# while с else (выполняется, если цикл завершился без break)
attempts = 0
max_attempts = 3

while attempts < max_attempts:
    password = input("Введите пароль: ")
    if password == "secret":
        print("Доступ разрешен")
        break
    attempts += 1
else:
    print("Доступ заблокирован")  # выполнится, если break не сработал

# while для очередей/потоков
from collections import deque

queue = deque([1, 2, 3])
while queue:
    item = queue.popleft()
    print(f"Обработка: {item}")
```

### enumerate()
`enumerate()` возвращает индекс и значение при итерации
```python
fruits = ['яблоко', 'банан', 'апельсин']

# Без enumerate (неудобно)
for i in range(len(fruits)):
    print(f"{i}: {fruits[i]}")

# С enumerate (Pythonic)
for i, fruit in enumerate(fruits):
    print(f"{i}: {fruit}")

# Можно указать начальный индекс
for i, fruit in enumerate(fruits, start=1):
    print(f"{i}. {fruit}")  # 1. яблоко, 2. банан, 3. апельсин

# enumerate с файлами
with open('file.txt') as f:
    for line_num, line in enumerate(f, 1):
        if 'error' in line:
            print(f"Ошибка в строке {line_num}: {line.strip()}")

# enumerate для поиска индекса
numbers = [10, 20, 30, 40, 50]
target = 30
for i, num in enumerate(numbers):
    if num == target:
        print(f"Найден на позиции {i}")
        break

# Генерация списка с индексами
indexed = [(i, x) for i, x in enumerate('abc')]
print(indexed)  # [(0, 'a'), (1, 'b'), (2, 'c')]
```

### zip()
`zip()` объединяет несколько итерируемых объектов в кортежи
```python
names = ['Анна', 'Иван', 'Мария']
ages = [25, 30, 28]
cities = ['Москва', 'СПб', 'Казань']

# Базовое использование
for name, age in zip(names, ages):
    print(f"{name}: {age} лет")

# С несколькими последовательностями
for name, age, city in zip(names, ages, cities):
    print(f"{name}, {age} лет, {city}")

# zip создает итератор, не список
zipped = zip(names, ages)
print(zipped)  # <zip object at ...>
print(list(zipped))  # [('Анна', 25), ('Иван', 30), ('Мария', 28)]

# Если последовательности разной длины
short = [1, 2]
long = [1, 2, 3, 4]

# zip останавливается на самой короткой
print(list(zip(short, long)))  # [(1, 1), (2, 2)]

# zip_longest для дополнения
from itertools import zip_longest
print(list(zip_longest(short, long, fillvalue=0)))  # [(1, 1), (2, 2), (0, 3), (0, 4)]

# Транспонирование матрицы
matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
transposed = list(zip(*matrix))
print(transposed)  # [(1, 4, 7), (2, 5, 8), (3, 6, 9)]

# Создание словаря из двух списков
keys = ['name', 'age', 'city']
values = ['Анна', 25, 'Москва']
dictionary = dict(zip(keys, values))
print(dictionary)  # {'name': 'Анна', 'age': 25, 'city': 'Москва'}

# Параллельная итерация с enumerate
for i, (name, age) in enumerate(zip(names, ages)):
    print(f"{i}: {name}, {age}")
```

### reversed()

`reversed()` возвращает итератор для обратной итерации.

```python
# Для последовательностей
fruits = ['яблоко', 'банан', 'апельсин']
for fruit in reversed(fruits):
    print(fruit)  # апельсин, банан, яблоко

# Для строк
text = "hello"
for char in reversed(text):
    print(char)  # o, l, l, e, h

# Для range
for i in reversed(range(5)):
    print(i)  # 4, 3, 2, 1, 0

# Список в обратном порядке
numbers = [1, 2, 3, 4, 5]
rev_numbers = list(reversed(numbers))
print(rev_numbers)  # [5, 4, 3, 2, 1]

# То же самое, но numbers.reverse() изменяет оригинал
numbers.reverse()
print(numbers)  # [5, 4, 3, 2, 1]

# Срез тоже создает обратный список (но копирует)
numbers = [1, 2, 3, 4, 5]
rev_slice = numbers[::-1]
print(rev_slice)  # [5, 4, 3, 2, 1]

# reversed создает итератор, экономя память
big_list = list(range(1000000))
rev_iter = reversed(big_list)  # O(1) памяти
rev_copy = big_list[::-1]      # O(n) памяти, новый список

# Для пользовательских классов нужно реализовать __reversed__ или __len__ + __getitem__
```

### Обход словарей и множеств

```python
user = {
    'name': 'Анна',
    'age': 25,
    'city': 'Москва',
    'verified': True
}

# По умолчанию итерация по ключам
for key in user:
    print(f"{key}: {user[key]}")

# Явно по ключам
for key in user.keys():
    print(key)

# По значениям
for value in user.values():
    print(value)

# По парам ключ-значение (рекомендуется)
for key, value in user.items():
    print(f"{key}: {value}")

# Сортировка ключей
for key in sorted(user.keys()):
    print(f"{key}: {user[key]}")

# Сортировка по значениям
for key, value in sorted(user.items(), key=lambda item: item[1]):
    print(f"{key}: {value}")

# Изменение словаря во время итерации (опасно!)
# Плохо:
# for key in user:
#     if key == 'age':
#         del user[key]  # RuntimeError!

# Хорошо: итерируемся по копии ключей
for key in list(user.keys()):
    if key == 'age':
        del user[key]  # безопасно

# Или создаем новый словарь
user = {k: v for k, v in user.items() if k != 'age'}

# Множества
colors = {'red', 'green', 'blue'}

# Простая итерация (порядок не гарантирован)
for color in colors:
    print(color)

# sorted для гарантии порядка
for color in sorted(colors):
    print(color)
```

## Управление циклами

### break

`break` полностью прекращает выполнение цикла.

```python
# Поиск элемента
numbers = [1, 3, 5, 7, 9, 11]
target = 7

for num in numbers:
    if num == target:
        print(f"Найдено: {num}")
        break
else:
    print(f"{target} не найден")  # выполнится, если break не сработал

# break во вложенных циклах прерывает только внутренний цикл
for i in range(3):
    print(f"i = {i}")
    for j in range(3):
        if j == 1:
            break  # прерывает только цикл по j
        print(f"  j = {j}")

# Бесконечный цикл с условием выхода
while True:
    command = input("Введите команду (quit для выхода): ")
    if command == 'quit':
        break
    execute(command)

# break в try/finally (finally выполнится!)
for i in range(5):
    try:
        if i == 3:
            break
        print(i)
    finally:
        print(f"finally для i={i}")
# finally выполняется перед break
```

### continue

`continue` пропускает остаток текущей итерации и переходит к следующей.

```python
# Вывод только четных чисел
for i in range(10):
    if i % 2 != 0:
        continue
    print(i)  # 0, 2, 4, 6, 8

# Фильтрация данных
data = [1, -2, 3, -4, 5, 0, -6]

for value in data:
    if value <= 0:
        continue
    print(f"Обработка: {value}")

# continue в while
counter = 0
while counter < 10:
    counter += 1
    if counter % 2 == 0:
        continue
    print(f"Нечетное: {counter}")

# continue пропускает остаток итерации, но не влияет на finally
for i in range(5):
    try:
        if i == 2:
            continue
        print(i)
    finally:
        print(f"finally для i={i}")  # выполняется всегда
```

## Сопоставление с образцом (Python 3.10+)

### match/case

`match` — это структурное сопоставление с образцом, аналогичное `switch` в других языках, но гораздо мощнее.

```python
# Базовый синтаксис
def http_status(code):
    match code:
        case 200:
            return "OK"
        case 404:
            return "Not Found"
        case 500:
            return "Internal Server Error"
        case _:  # wildcard (значение по умолчанию)
            return "Unknown Status"

print(http_status(200))  # OK
print(http_status(418))  # Unknown Status

# match может сопоставлять не только константы
def process_value(value):
    match value:
        case 0:
            print("Ноль")
        case 1 | 2 | 3:  # OR паттерн
            print("Маленькое число")
        case int():
            print(f"Целое число: {value}")
        case str():
            print(f"Строка: {value}")
        case _:
            print(f"Что-то другое: {type(value).__name__}")
```

## Сравнение match/case с if/elif

```python
# Традиционный подход с if/elif
def process_if(value):
    if isinstance(value, int):
        if value == 0:
            return "ноль"
        elif 1 <= value <= 3:
            return "маленькое"
        else:
            return "большое целое"
    elif isinstance(value, str):
        if not value:
            return "пустая строка"
        elif value.isdigit():
            return "строковое число"
        else:
            return "обычная строка"
    elif value is None:
        return "ничего"
    else:
        return "другой тип"

# С match/case (чище и выразительнее)
def process_match(value):
    match value:
        case 0:
            return "ноль"
        case 1 | 2 | 3:
            return "маленькое"
        case int():
            return "большое целое"
        case "":
            return "пустая строка"
        case str() as s if s.isdigit():
            return "строковое число"
        case str():
            return "обычная строка"
        case None:
            return "ничего"
        case _:
            return "другой тип"
```

| Аспект | if/elif | match/case |
|--------|---------|------------|
| Читаемость | Хорошо для простых условий | Лучше для сложной структуры |
| Сопоставление типов | Через `isinstance()` | Встроенный синтаксис |
| Распаковка | Вручную | Автоматическая |
| Вложенные структуры | Много кода | Элегантно |
| Guards | Через `if` | Через `if` в case |
| Производительность | Обычно быстрее | Немного медленнее |

## Обработка исключений

### Что такое исключения?

**Исключение (exception)** — это событие, возникающее во время выполнения программы, которое нарушает нормальный поток инструкций.

```python
# Примеры исключений
# ZeroDivisionError: деление на ноль
# TypeError: операция неподходящего типа
# ValueError: значение недопустимо
# FileNotFoundError: файл не найден
# KeyError: ключ не найден в словаре
# IndexError: индекс вне диапазона

# Когда возникает исключение, программа останавливается
# x = 1 / 0  # ZeroDivisionError: division by zero
# print("Эта строка не выполнится")
```

### Типы исключений

```python
# Иерархия исключений (упрощенно)
"""
BaseException
 ├── SystemExit
 ├── KeyboardInterrupt
 └── Exception
      ├── ArithmeticError
      │    ├── ZeroDivisionError
      │    └── FloatingPointError
      ├── LookupError
      │    ├── IndexError
      │    └── KeyError
      ├── ValueError
      ├── TypeError
      ├── FileNotFoundError
      └── ... (много других)
"""

# Все пользовательские исключения должны наследовать от Exception
class CustomError(Exception):
    """Мое пользовательское исключение"""
    pass

class ValidationError(Exception):
    def __init__(self, field, message):
        self.field = field
        self.message = message
        super().__init__(f"{field}: {message}")
```

### try/except

```python
# Базовая конструкция
try:
    # Код, который может вызвать исключение
    number = int(input("Введите число: "))
    result = 10 / number
    print(f"Результат: {result}")
except ZeroDivisionError:
    # Обработка конкретного исключения

except Exception as e:

# Несколько исключений в одном except

    data = [1, 2, 3]
    index = int(input("Индекс: "))
    print(data[index])
except (ValueError, IndexError) as e:
    print(f"Ошибка ввода или индекса: {e}")

# except без типа (перехватывает всё) — ОПАСНО!
try:
    dangerous_operation()
except:  # перехватит даже SystemExit и KeyboardInterrupt!
    print("Ошибка")  # не делайте так!

# Правильно: перехватывать Exception

    dangerous_operation()
```

### else в исключениях

Блок `else` выполняется, если в `try` не было исключений.

```python
def divide_numbers(a, b):
    try:
        result = a / b
    except ZeroDivisionError:
        print("Ошибка: деление на ноль")
        return None
    else:
        print(f"Успешно: {a} / {b} = {result}")
        return result
    finally:
        print("Блок finally выполняется всегда")

# Пример использования
result = divide_numbers(10, 2)
print(f"Результат: {result}")

result = divide_numbers(10, 0)
print(f"Результат: {result}")

# else полезно, когда нужно различать успешное выполнение и обработку ошибок
def process_file(filename):
    try:
        file = open(filename, 'r')
    except FileNotFoundError:
        print(f"Файл {filename} не найден")
        return
    else:
        # Этот код выполняется только если файл открылся
        content = file.read()
        print(f"Файл прочитан, длина: {len(content)}")
        file.close()
```

### finally

`finally` выполняется всегда, независимо от того, было исключение или нет.

```python
# Освобождение ресурсов
def read_file_safe(filename):
    file = None
    try:
        file = open(filename, 'r')
        return file.read()
    except FileNotFoundError:
        print(f"Файл {filename} не найден")
        return None
    finally:
        if file:
            file.close()
            print("Файл закрыт")

# finally выполняется даже при return
def test_finally():
    try:
        print("В try")
        return "return из try"
    finally:
        print("В finally")  # выполнится перед return!

print(test_finally())
# Вывод:
# В try
# В finally
# return из try

# finally выполняется даже при исключении
try:
    print("В try")
    raise ValueError("Ошибка")
finally:
    print("В finally")  # выполнится
# потом исключение поднимается дальше

# Комбинация try/except/finally
try:

except ZeroDivisionError:
```

```python
    if age < 0:

    if age > 150:
        raise ValueError("Возраст слишком большой")
    return age

try:
    age = validate_age(-5)
except ValueError as e:
    print(f"Ошибка валидации: {e}")

# Проброс исключения (re-raise)
def process_data(data):
    try:
        result = complex_calculation(data)
    except ZeroDivisionError:
        print("Логирование ошибки...")
        raise  # пробрасываем то же исключение дальше

# Создание иерархии своих исключений
class DatabaseError(Exception):

    pass

    pass

    """Ошибка запроса"""
    pass

def query_db(sql):
    if not connected:
        raise ConnectionError("Нет подключения к БД")
    if not is_valid(sql):
        raise QueryError("Некорректный SQL")
    # ...

# raise from для цепочки исключений
def convert_to_int(value):
    try:
        return int(value)
    except ValueError as e:
        raise ValueError(f"Не могу преобразовать '{value}' в число") from e

# raise from None для подавления контекста
def safe_convert(value):
    try:
        return int(value)
    except ValueError:
        raise ValueError(f"Не могу преобразовать '{value}'") from None
```

## Частые ошибки

### 1. Путаница с отступами

```python
# Ошибка
if x > 0:
print("x положительный")  # IndentationError

# Ошибка
if x > 0:
    print("x положительный")
  print("еще что-то")  # IndentationError: unexpected indent

# Смешивание табуляции и пробелов
# В Python 3 это SyntaxError
```

### 2. Забытый break в цикле

```python
# Ошибка: бесконечный цикл
i = 0
while i < 10:
    print(i)
    # забыли i += 1

# Ошибка: break не там
for i in range(10):
    print(i)
    if i == 5:
        break  # правильно, но...
    # break здесь прервет после первой итерации
```

### 3. Изменение списка во время итерации

```python
# Ошибка
numbers = [1, 2, 3, 4, 5]
for num in numbers:
    if num % 2 == 0:
        numbers.remove(num)  # сдвигает индексы!
print(numbers)  # [1, 3, 5]? Нет, [1, 3, 4, 5]!

# Правильно
numbers = [1, 2, 3, 4, 5]
numbers = [num for num in numbers if num % 2 != 0]
```

### 4. Пустой except

```python
# Ошибка: слишком широкий except
try:
    dangerous_operation()
except:  # перехватит всё, включая SystemExit!
    pass

# Правильно
try:
    dangerous_operation()
except Exception as e:
    log_error(e)
    raise  # или обработать конкретно
```

### 5. Неправильный порядок except

```python
# Ошибка
try:
    x = int(input())
    result = 10 / x
except Exception:  # слишком общий
    print("Ошибка")
except ZeroDivisionError:  # никогда не выполнится
    print("Деление на ноль")

# Правильно: от конкретного к общему
try:
    x = int(input())
    result = 10 / x
except ZeroDivisionError:
    print("Деление на ноль")
except ValueError:
    print("Не число")
except Exception:
    print("Другая ошибка")
```

### 6. Забытая запятая в кортеже исключений

```python
# Ошибка
try:
    x = int(input())
except ValueError, ZeroDivisionError:  # SyntaxError в Python 3
    pass

# Правильно
try:
    x = int(input())
except (ValueError, ZeroDivisionError):
    pass
```

### 7. Неправильное использование else в циклах

```python

    if i == 3:
        break
else:
    print("Цикл завершен нормально")  # не выполнится
```

## Лучшие практики

### 1. Используйте guard clauses для уменьшения вложенности

```python
# Плохо
def process_user(user):
    if user:
        if user.is_active:
            if user.has_permission:
                return do_something(user)
            else:
                return "Нет прав"
        else:
            return "Неактивен"
    else:
        return "Нет пользователя"

# Хорошо
def process_user(user):
    if not user:
        return "Нет пользователя"
    if not user.is_active:
        return "Неактивен"
    if not user.has_permission:
        return "Нет прав"
    return do_something(user)
```

### 2. Используйте enumerate вместо range(len())

```python
# Плохо
fruits = ['яблоко', 'банан', 'апельсин']
for i in range(len(fruits)):
    print(f"{i}: {fruits[i]}")

# Хорошо
for i, fruit in enumerate(fruits):
    print(f"{i}: {fruit}")
```

### 3. Используйте zip для параллельной итерации

```python
# Плохо
names = ['Анна', 'Иван']
ages = [25, 30]
for i in range(len(names)):
    print(f"{names[i]}: {ages[i]}")

# Хорошо
for name, age in zip(names, ages):
    print(f"{name}: {age}")
```

### 4. Специфичные исключения

```python
# Плохо
try:
    result = calculate(x)
except Exception:
    print("Ошибка")

# Хорошо
try:
    result = calculate(x)
except (ValueError, ZeroDivisionError) as e:
    print(f"Ошибка расчета: {e}")
```

### 5. Используйте контекстные менеджеры для ресурсов

```python
# Плохо
f = open('file.txt')
try:
    data = f.read()
finally:
    f.close()

# Хорошо
with open('file.txt') as f:
    data = f.read()
```

### 6. Избегайте пустых except

```python
# Плохо
try:
    do_something()
except:
    pass

# Хорошо
try:
    do_something()
except SpecificError:
    # обработать конкретно
    pass
except Exception as e:
    log_error(e)
    raise
```

### 7. Используйте match/case для сложной структуры

```python
# Плохо (много isinstance и вложенных if)
def process_node(node):
    if isinstance(node, dict):
        if 'type' in node:
            if node['type'] == 'add':
                return node['left'] + node['right']
            elif node['type'] == 'sub':
                return node['left'] - node['right']
    # ...

# Хорошо (Python 3.10+)
def process_node(node):
    match node:
        case {'type': 'add', 'left': l, 'right': r}:
            return l + r
        case {'type': 'sub', 'left': l, 'right': r}:
            return l - r
        case _:
            raise ValueError(f"Unknown node: {node}")
```

## Частые вопросы и выводы

### FAQ

**В: В чем разница между `if/elif` и `match/case`?**
**О:** `if/elif` лучше для простых условий и диапазонов. `match/case` лучше для сопоставления со структурой данных (классы, словари, кортежи) и распаковки.

**В: Когда использовать `while`, а когда `for`?**
**О:** `for` — когда знаете количество итераций или итерируете по коллекции. `while` — когда условие завершения не связано с количеством итераций (например, ожидание события).

**В: Что произойдет, если не обработать исключение?**
**О:** Программа завершится с traceback. В интерактивной сессии исключение покажется, но сессия продолжит работу.

**В: Можно ли использовать `else` без `except`?**
**О:** Да, но редко. `try/else` без `except` выполнит `else` если в `try` не было исключений, но если исключение будет, оно не перехватится.

**В: Как прервать внешний цикл из внутреннего?**
**О:** Используйте флаг, вынесите в функцию с `return`, используйте `for/else` с `break` внешнего, или `itertools.product`.

**В: Что быстрее: `if` или `match`?**
**О:** Для простых условий `if` обычно быстрее. `match` добавляет небольшие накладные расходы, но для сложных структур он может быть эффективнее ручных проверок.

**В: Почему в Python нет `switch`?**
**О:** Раньше не было, теперь есть `match` (Python 3.10+), который гораздо мощнее традиционного `switch`.

### Ментальная модель управления потоком

```
Представьте программу как лабиринт:

Последовательное выполнение:
[Старт] → [Шаг 1] → [Шаг 2] → [Шаг 3] → [Финиш]

Ветвление (if/else):
[Старт] → [Условие?] 
              ├─ Да → [Блок А] → [Финиш]
              └─ Нет → [Блок Б] → [Финиш]

Циклы (for/while):
[Старт] → [Начало цикла] → [Тело цикла] → [Проверка] 
                                         ↻ да
                                         ↓ нет
                                      [Финиш]

Исключения:
[Старт] → [Попытка] → [Ошибка?] → [Обработка] → [Финиш]
                         ↓ нет
                      [Продолжение]
```
