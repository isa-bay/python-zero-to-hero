# Основы функций

## Что такое функция? Зачем нужны функции ?
**Функция** — это именованный блок кода, предназначенный для решения конкретной задачи. Функции являются фундаментальными строительными блоками любой программы.

### Зачем нужны функции?
```python
# 1. ПЕРЕИСПОЛЬЗОВАНИЕ КОДА (DRY — Don't Repeat Yourself)
# Без функции (плохо)
name1 = "Анна"
print(f"Привет, {name1}! Добро пожаловать!")
name2 = "Иван"
print(f"Привет, {name2}! Добро пожаловать!")
name3 = "Мария"
print(f"Привет, {name3}! Добро пожаловать!")

# С функцией (хорошо)
def greet(name):
    print(f"Привет, {name}! Добро пожаловать!")

greet("Анна")
greet("Иван")
greet("Мария")

# 2. МОДУЛЬНОСТЬ И РАЗДЕЛЕНИЕ ОТВЕТСТВЕННОСТИ
# Функции позволяют разбить сложную задачу на простые шаги
def get_user_input():
    """Получение данных от пользователя"""
    name = input("Введите имя: ")
    age = int(input("Введите возраст: "))
    return name, age

def validate_age(age):
    """Проверка корректности возраста"""
    if age < 0 or age > 150:
        raise ValueError("Некорректный возраст")
    return True

def create_greeting(name, age):
    """Создание приветствия"""
    return f"Привет, {name}! Тебе {age} лет."

def main():
    """Главная функция программы"""
    name, age = get_user_input()
    validate_age(age)
    message = create_greeting(name, age)
    print(message)

# 3. АБСТРАКЦИЯ — скрытие деталей реализации
def calculate_discount(price, customer_type):
    """Вычисляет скидку, скрывая сложную логику"""
    # Здесь может быть сложная логика с БД, правилами и т.д.
    if customer_type == "VIP":
        return price * 0.2
    elif customer_type == "regular":
        return price * 0.1
    return 0

# Пользователь функции не знает, как именно считается скидка
total = 1000 - calculate_discount(1000, "VIP")

# 4. ТЕСТИРОВАНИЕ — функции легко тестировать изолированно
def add(a, b):
    return a + b

# Тест
assert add(2, 2) == 4
assert add(-1, 1) == 0
assert add(0, 0) == 0
```

### Математическое определение vs Python
```python
# Математическая функция: f(x) = x²
def f(x):
    return x ** 2

# В Python функции могут:
# - Иметь побочные эффекты (print, запись в файл)
# - Изменять переданные объекты
# - Не возвращать значение
```

### Вызов функции

### Порядок выполнения
```python
def demonstrate_flow():
    print("1. Функция вызвана")
    print("2. Выполняется тело")
    print("3. Функция завершается")
    return "4. Возвращаемое значение"

print("До вызова")
result = demonstrate_flow()
print("После вызова")
print(f"Результат: {result}")

# Вывод:
# До вызова
# 1. Функция вызвана
# 2. Выполняется тело
# 3. Функция завершается
# После вызова
# Результат: 4. Возвращаемое значение
```

## Анатомия функции

### Полный разбор структуры
```python
def calculate_bmi(weight: float, height: float) -> float:
    """
    Рассчитывает индекс массы тела (BMI).
    
    Args:
        weight: Вес в килограммах
        height: Рост в метрах
    
    Returns:
        Значение BMI как float
    
    Raises:
        ValueError: Если вес или рост некорректны
    """
    # Валидация
    if weight <= 0 or height <= 0:
        raise ValueError("Вес и рост должны быть положительными")
    
    # Вычисление
    bmi = weight / (height ** 2)
    
    # Округление
    return round(bmi, 2)

# Разбор по частям:
# def            - ключевое слово
# calculate_bmi  - имя функции
# (weight, height) - параметры
# -> float       - аннотация возвращаемого типа
# :              - двоеточие, начало блока
# """..."""      - docstring
# тело функции   - с отступом
# return         - оператор возврата
```

### Компоненты функции
| Компонент | Обязательный | Описание |
|-----------|--------------|----------|
| `def` | ✅ | Ключевое слово, начинающее определение |
| Имя функции | ✅ | Идентификатор для вызова |
| Параметры | ✅ | Список в круглых скобках (может быть пустым) |
| Двоеточие | ✅ | Завершает заголовок функции |
| Тело функции | ✅ | Блок кода с отступом |
| `return` | ❌ | Возвращает значение и завершает функцию |
| `docstring` | ❌ | Строка документации |
| Аннотации | ❌ | Подсказки типов для параметров и возврата |

## return и возвращаемые значения

### Базовое использование return
```python
def add(a, b):
    return a + b

result = add(3, 5)  # result = 8

# return завершает выполнение функции
def early_return(x):
    if x < 0:
        return "Отрицательное"  # функция завершается здесь
    if x == 0:
        return "Ноль"           # или здесь
    return "Положительное"      # или здесь
    print("Этот код никогда не выполнится")

print(early_return(-5))  # "Отрицательное"
print(early_return(0))   # "Ноль"
print(early_return(5))   # "Положительное"
```

### Функции без return
```python
# Если нет return, функция возвращает None
def print_hello():
    print("Hello")

result = print_hello()  # Hello
print(result)           # None
print(print_hello())    # Hello \n None

# return без значения тоже возвращает None
def return_none():
    return

print(return_none())  # None

# Это полезно для функций с побочными эффектами
def log_message(msg):
    with open('log.txt', 'a') as f:
        f.write(f"{msg}\n")
    # неявно return None
```

### Возврат функций
```python
# Функция может возвращать другую функцию (замыкание)
def make_multiplier(n):
    def multiplier(x):
        return x * n
    return multiplier

times2 = make_multiplier(2)
times3 = make_multiplier(3)

print(times2(5))  # 10
print(times3(5))  # 15

# Фабрика функций
def make_operation(operation):
    if operation == "add":
        return lambda a, b: a + b
    elif operation == "sub":
        return lambda a, b: a - b
    elif operation == "mul":
        return lambda a, b: a * b
    else:
        return lambda a, b: None

add = make_operation("add")
print(add(5, 3))  # 8
```

### Возврат и обработка ошибок
```python
def divide(a, b):
    try:
        result = a / b
    except ZeroDivisionError:
        return float('inf')  # или None, или raise
    except TypeError:
        return None
    else:
        return result

# Иногда лучше raise, чем возвращать специальные значения
def divide_strict(a, b):
    if not isinstance(a, (int, float)) or not isinstance(b, (int, float)):
        raise TypeError("Аргументы должны быть числами")
    if b == 0:
        raise ValueError("Деление на ноль")
    return a / b
```

## Параметры и аргументы (базовые понятия)

### Параметры vs Аргументы
```python
# Параметры — переменные в определении функции
def func(param1, param2):  # param1, param2 — параметры
    return param1 + param2

# Аргументы — значения, передаваемые при вызове
result = func(5, 3)  # 5 и 3 — аргументы
```

### Позиционные аргументы
```python
def describe_person(name, age, city):
    print(f"{name}, {age} лет, {city}")

# Аргументы передаются в том же порядке
describe_person("Анна", 25, "Москва")
# Анна, 25 лет, Москва

# Важен порядок!
describe_person(25, "Анна", "Москва")
# 25, Анна лет, Москва  (семантически неверно!)
```

### Именованные аргументы (keyword arguments)
```python
def describe_person(name, age, city):
    print(f"{name}, {age} лет, {city}")

# Можно указывать имена параметров
describe_person(name="Анна", age=25, city="Москва")
describe_person(city="СПб", name="Иван", age=30)  # порядок не важен

# Смешивание позиционных и именованных
describe_person("Анна", city="Москва", age=25)  # OK
# describe_person(name="Анна", 25, "Москва")  # SyntaxError!
# Позиционные должны идти до именованных
```

### Параметры по умолчанию
```python
def greet(name, greeting="Привет", punctuation="!"):
    print(f"{greeting}, {name}{punctuation}")

# Можно опускать параметры с умолчаниями
greet("Анна")                    # Привет, Анна!
greet("Анна", "Здравствуйте")    # Здравствуйте, Анна!

# Важно: значения по умолчанию вычисляются ОДИН раз при определении!
def bad_append(item, target=[]):  # список создается один раз!
    target.append(item)
    return target

print(bad_append(1))  # [1]
print(bad_append(2))  # [1, 2]  — тот же список!

# Правильно:
def good_append(item, target=None):
    if target is None:
        target = []
    target.append(item)
    return target
```

```python
    print(f"Дополнительные именованные: {kwargs}")

flexible_function(1, 2, 3, 4, 5, x=10, y=20)
```

### Распаковка аргументов
```python
def point(x, y, z):
    print(f"x={x}, y={y}, z={z}")

# Распаковка списка/кортежа

point(*coords)  # x=10, y=20, z=30

```

## Документирование функций (docstrings)

### Стили docstring
```python
# PEP 257 — соглашения по docstring

# 1. Однострочный docstring
def add(a, b):
    """Возвращает сумму a и b."""
    return a + b

# 2. Многострочный docstring (рекомендуемый стиль)
def calculate_bmi(weight, height):
    """
    Рассчитывает индекс массы тела (BMI).
    
    Аргументы:
        weight (float): Вес в килограммах
        height (float): Рост в метрах
    
    Возвращает:
        float: Значение BMI, округленное до 2 знаков
    
    Пример:
        >>> calculate_bmi(70, 1.75)
        22.86
    
    Исключения:
        ValueError: Если вес или рост <= 0
    """
    if weight <= 0 or height <= 0:
        raise ValueError("Вес и рост должны быть положительными")
    return round(weight / (height ** 2), 2)

# 3. Google style (популярен)
def google_style(name, age, *args, **kwargs):
    """
    Пример Google style docstring.
    
    Args:
        name (str): Имя пользователя
        age (int): Возраст пользователя
        *args: Дополнительные позиционные аргументы
        **kwargs: Дополнительные именованные аргументы
    
    Returns:
        bool: True если успешно, иначе False
    
    Raises:
        ValueError: Если возраст отрицательный
    
    Examples:
        >>> google_style("Анна", 25)
        True
    """
    pass

# 4. NumPy/SciPy style
def numpy_style(x, y):
    """
    Пример NumPy style docstring.
    
    Parameters
    ----------
    x : float
        Первое число
    y : float
        Второе число
    
    Returns
    -------
    float
        Результат операции
    
    See Also
    --------
    add : Похожая функция
    """
    return x + y
```

## Функция vs процедура

### Теоретическое различие
В теории программирования:
- **Функция** — принимает аргументы, возвращает значение, не имеет побочных эффектов (чистая функция)
- **Процедура** — принимает аргументы, выполняет действия, может не возвращать значение, имеет побочные эффекты

### В Python нет процедур, только функции
```python
# В Python всё — функции, но они могут быть разными

# 1. Функция, возвращающая значение (похожа на математическую функцию)
def add(a, b):
    return a + b

# 2. Функция с побочным эффектом (процедура в терминах других языков)
def print_message(msg):
    print(msg)  # побочный эффект (вывод на экран)
    # return None (неявно)

# 3. Функция, изменяющая объект
def add_to_list(lst, item):
    lst.append(item)  # изменяет переданный список
    # return None

# 4. Чистая функция (pure function) — нет побочных эффектов
def pure_function(x):
    return x ** 2  # только возвращает значение, не меняет внешнее состояние
```

### Чистые функции vs Нечистые
```python
# ЧИСТАЯ ФУНКЦИЯ (pure)
# - Результат зависит только от аргументов
# - Нет побочных эффектов
# - Для одинаковых аргументов всегда одинаковый результат

def pure_add(a, b):
    return a + b

# НЕЧИСТАЯ ФУНКЦИЯ (impure)
# - Зависит от внешнего состояния
# - Имеет побочные эффекты
# - Может давать разные результаты для одинаковых аргументов

counter = 0
def impure_increment():
    global counter
    counter += 1  # изменяет глобальное состояние
    return counter

def impure_print(x):
    print(x)  # побочный эффект
    return x

def impure_random():
    import random
    return random.random()  # результат непредсказуем
```

### Преимущества чистых функций
```python
# 1. Легко тестировать
assert pure_add(2, 2) == 4
assert pure_add(-1, 1) == 0

# 2. Легко кэшировать (мемоизация)
from functools import lru_cache

@lru_cache(maxsize=None)
def fibonacci(n):
    if n < 2:
        return n
    return fibonacci(n-1) + fibonacci(n-2)

# 3. Потокобезопасны
# 4. Параллелизм без блокировок
# 5. Предсказуемость
```

## Функции как объекты первого класса

**Функции в Python — объекты первого класса (first-class citizens)**. Это означает, что функции могут быть:
1. Присвоены переменным
2. Переданы как аргументы в другие функции
3. Возвращены из других функций
4. Храниться в структурах данных

### 1. Присваивание переменным
```python
def greet(name):
    return f"Hello, {name}!"

# Функцию можно присвоить переменной
my_function = greet
print(my_function("Анна"))  # Hello, Анна!

# Переменная ссылается на ту же функцию
print(greet is my_function)  # True

# Можно даже удалить оригинальное имя
del greet
print(my_function("Иван"))  # Hello, Иван!
# print(greet("Петр"))  # NameError!
```

### 2. Хранение в структурах данных
```python
def add(a, b): return a + b
def subtract(a, b): return a - b
def multiply(a, b): return a * b
def divide(a, b): return a / b

# Список функций
operations = [add, subtract, multiply, divide]
for op in operations:
    print(op(10, 5))
# 15
# 5
# 50
# 2.0

# Словарь функций
calculator = {
    '+': add,
    '-': subtract,
    '*': multiply,
    '/': divide
}

def calculate(a, b, operator):
    return calculator[operator](a, b)

print(calculate(10, 5, '+'))  # 15
print(calculate(10, 5, '*'))  # 50

# Кортеж функций
math_ops = (add, subtract, multiply)
```

### 3. Передача функций как аргументы
```python
def apply_twice(func, arg):
    """Применяет функцию дважды к аргументу"""
    return func(func(arg))

def increment(x):
    return x + 1

print(apply_twice(increment, 5))  # 7 (5+1+1)

def square(x):
    return x ** 2

print(apply_twice(square, 2))  # 16 (2²=4, 4²=16)

# Встроенные функции высшего порядка
numbers = [1, 2, 3, 4, 5]

# map — применяет функцию к каждому элементу
squared = list(map(lambda x: x**2, numbers))
print(squared)  # [1, 4, 9, 16, 25]

# filter — фильтрует элементы по функции
evens = list(filter(lambda x: x % 2 == 0, numbers))
print(evens)  # [2, 4]

# sorted — сортировка с ключом
words = ['banana', 'apple', 'cherry', 'date']
sorted_by_len = sorted(words, key=len)
print(sorted_by_len)  # ['date', 'apple', 'banana', 'cherry']
```

### 4. Возврат функций (замыкания)
```python
def make_multiplier(factor):
    """Возвращает функцию, умножающую на factor"""
    def multiplier(x):
        return x * factor
    return multiplier

double = make_multiplier(2)
triple = make_multiplier(3)

print(double(5))  # 10
print(triple(5))  # 15

# Замыкание "запоминает" окружение
def make_counter():
    count = 0
    def counter():
        nonlocal count
        count += 1
        return count
    return counter

c1 = make_counter()
print(c1())  # 1
print(c1())  # 2
print(c1())  # 3

c2 = make_counter()
print(c2())  # 1 (независимый счетчик)
```

### 5. Функции как атрибуты классов и методов

### 7. Декораторы — функции, изменяющие функции
```python
# Декоратор — функция, принимающая функцию и возвращающая функцию
def timer(func):
    import time
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        end = time.time()
        print(f"{func.__name__} выполнена за {end-start:.4f} сек")
        return result
    return wrapper

@timer
def slow_function():
    import time
    time.sleep(1)
    return "Готово"

slow_function()  # slow_function выполнена за 1.0001 сек

# Несколько декораторов
def bold(func):
    def wrapper():
        return f"<b>{func()}</b>"
    return wrapper

def italic(func):
    def wrapper():
        return f"<i>{func()}</i>"
    return wrapper

@bold
@italic
def hello():
    return "Hello"

print(hello())  # <b><i>Hello</i></b>
```

### 9. Функции как контекстные менеджеры
```python
from contextlib import contextmanager

@contextmanager
def temporary_change(obj, attr, value):
    """Временно меняет атрибут объекта"""
    old_value = getattr(obj, attr)
    setattr(obj, attr, value)
    try:
        yield
    finally:
        setattr(obj, attr, old_value)

class Config:
    debug = False

config = Config()
with temporary_change(config, 'debug', True):
    print(config.debug)  # True
print(config.debug)      # False
```

### 10. Функции как паттерны проектирования
```python
# Стратегия (Strategy)
def strategy_add(a, b): return a + b
def strategy_subtract(a, b): return a - b
def strategy_multiply(a, b): return a * b

class Calculator:
    def __init__(self, strategy):
        self.strategy = strategy
    
    def execute(self, a, b):
        return self.strategy(a, b)

calc = Calculator(strategy_add)
print(calc.execute(5, 3))  # 8
calc.strategy = strategy_multiply
print(calc.execute(5, 3))  # 15

# Фабрика (Factory)
def create_formatter(format_type):
    if format_type == 'json':
        return lambda data: json.dumps(data)
    elif format_type == 'csv':
        return lambda data: ','.join(str(x) for x in data)
    else:
        return lambda data: str(data)
```

## Частые вопросы и ключевые выводы

### FAQ
**В: Что такое функция одним предложением?**
**О:** Функция — это именованный блок кода, который можно вызывать многократно, возможно с разными аргументами.

**В: Зачем нужен `return`?**
**О:** `return` возвращает значение из функции и завершает её выполнение. Без `return` функция возвращает `None`.

**В: В чем разница между параметром и аргументом?**
**О:** Параметр — это переменная в определении функции. Аргумент — конкретное значение, переданное при вызове.

**В: Что такое функция первого класса?**
**О:** Это значит, что функцию можно присваивать переменным, передавать в другие функции, возвращать из функций и хранить в структурах данных.

**В: Когда использовать `*args` и `**kwargs`?**
**О:** Когда нужно принимать произвольное количество аргументов: `*args` для позиционных, `**kwargs` для именованных.

**В: Почему нельзя использовать изменяемые объекты как значения по умолчанию?**
**О:** Потому что они создаются один раз при определении функции и будут общими для всех вызовов.

**В: Что такое чистая функция?**
**О:** Функция, которая не имеет побочных эффектов и для одинаковых аргументов всегда возвращает одинаковый результат.
