# Аргументы функций

Аргументы функций в питоне — это одна из самых гибких и мощных систем среди всех языков программирования.
Понимание того, как работают аргументы, критически важно для написания чистого, поддерживаемого и эффективного кода
```python
# Простой пример, демонстрирующий разные типы аргументов
def example(pos1, pos2, /, pos_or_kwd, *, kwd1, kwd2="default"):
    """Демонстрация всех видов параметров"""
    print(f"pos1={pos1}, pos2={pos2}")
    print(f"pos_or_kwd={pos_or_kwd}")
    print(f"kwd1={kwd1}, kwd2={kwd2}")
```

## Позиционные аргументы

### Основы позиционных аргументов
**Позиционные аргументы (positional arguments)** — это аргументы, которые передаются в функцию в том же порядке, в котором определены параметры
```python
def describe_person(name, age, city):
    print(f"{name}, {age} лет, {city}")

# Аргументы передаются ПО ПОРЯДКУ
describe_person("Анна", 25, "Москва")   # Анна, 25 лет, Москва
describe_person("Москва", "Анна", 25)   # Москва, Анна лет, 25 (семантически неверно!)
```

### Обязательность позиционных аргументов
```python
def greet(name, greeting):
    return f"{greeting}, {name}!"

# Все позиционные аргументы обязательны
print(greet("Анна", "Привет"))  # Привет, Анна!
# print(greet("Анна"))           # TypeError: missing 1 argument
# print(greet())                  # TypeError: missing 2 arguments
```

### Позиционные аргументы с / (Python 3.8+)
Синтаксис `/` в определении функции указывает, что параметры слева от него могут быть переданы **только позиционно**
```python
def pow_function(x, y, /):
    """x и y могут быть только позиционными"""
    return x ** y

# Правильно:
print(pow_function(2, 3))     # 8

# Неправильно:
# print(pow_function(x=2, y=3))  # TypeError: pow_function() got some positional-only arguments passed as keyword arguments: 'x, y'

# Реальный пример из стандартной библиотеки
help(pow)  # pow(x, y, /) — x и y только позиционные

# Когда это полезно?
def safe_divide(dividend, divisor, /):
    """Параметры с понятными именами только для документации"""
    if divisor == 0:
        raise ValueError("Division by zero")
    return dividend / divisor

# Теперь имена параметров не важны при вызове
safe_divide(10, 2)     # OK
# safe_divide(dividend=10, divisor=2)  # TypeError!
```

## Именованные (ключевые) аргументы

### Основы именованных аргументов
**Именованные аргументы (keyword arguments)** передаются с указанием имени параметра
```python
def describe_person(name, age, city):
    print(f"{name}, {age} лет, {city}")

# Вызов с именованными аргументами (порядок не важен)
describe_person(name="Анна", age=25, city="Москва")
describe_person(city="СПб", name="Иван", age=30)

# Смешивание позиционных и именованных
describe_person("Анна", city="Москва", age=25)  # позиционные сначала!
# describe_person(name="Анна", 25, "Москва")    # SyntaxError!
```

### Именованные аргументы с * (Python 3+)
Синтаксис `*` в определении функции указывает, что все параметры справа от него могут быть переданы **только по имени**
```python
def create_user(name, *, age, city):
    """name — позиционный, age и city — только именованные"""
    return {"name": name, "age": age, "city": city}

# Правильно:
print(create_user("Анна", age=25, city="Москва"))
# {'name': 'Анна', 'age': 25, 'city': 'Москва'}

# Неправильно:
# print(create_user("Анна", 25, "Москва"))  # TypeError: create_user() takes 1 positional argument but 3 were given

# Зачем это нужно? Для ясности кода!
def send_email(to, subject, *, cc=None, bcc=None, attachments=None):
    """to и subject — обязательные позиционные
       cc, bcc, attachments — опциональные именованные"""
    print(f"To: {to}")
    print(f"Subject: {subject}")
    if cc:
        print(f"Cc: {cc}")
    if bcc:
        print(f"Bcc: {bcc}")
    # отправка письма...

send_email("user@example.com", "Hello")
send_email("user@example.com", "Hello", cc="boss@example.com", attachments=["file.pdf"])
```

### Полный синтаксис параметров (Python 3.8+)
```python
def full_example(
    pos_only1, pos_only2, /,  # только позиционные
    pos_or_kwd1, pos_or_kwd2,  # можно и так, и так
    *,                         # разделитель: дальше только именованные
    kwd_only1, kwd_only2       # только именованные
):
    print(f"pos_only: {pos_only1}, {pos_only2}")
    print(f"pos_or_kwd: {pos_or_kwd1}, {pos_or_kwd2}")
    print(f"kwd_only: {kwd_only1}, {kwd_only2}")

# Правильные вызовы:
full_example(1, 2, 3, 4, kwd_only1=5, kwd_only2=6)
full_example(1, 2, pos_or_kwd1=3, pos_or_kwd2=4, kwd_only1=5, kwd_only2=6)

# Неправильные вызовы:
# full_example(1, 2, 3, 4, 5, 6)  # 5,6 должны быть именованными
# full_example(pos_only1=1, pos_only2=2, ...)  # pos_only должны быть позиционными
```

## Аргументы по умолчанию

### Базовое использование
```python
def greet(name, greeting="Привет", punctuation="!"):
    """name — обязательный, greeting и punctuation — опциональные"""
    return f"{greeting}, {name}{punctuation}"

print(greet("Анна"))                 # Привет, Анна!
print(greet("Анна", "Здравствуйте"))  # Здравствуйте, Анна!
print(greet("Анна", "Hi", "!!!"))     # Hi, Анна!!!
print(greet("Анна", punctuation="?")) # Привет, Анна?
```

### Важное предупреждение: изменяемые объекты по умолчанию
```python
# ПЛОХО — изменяемый объект по умолчанию
def bad_append(item, target=[]):
    """target создается ОДИН РАЗ при определении функции!"""
    target.append(item)
    return target

print(bad_append(1))  # [1]
print(bad_append(2))  # [1, 2] — тот же список!
print(bad_append(3))  # [1, 2, 3]

# ХОРОШО — None как маркер
def good_append(item, target=None):
    if target is None:
        target = []
    target.append(item)
    return target

print(good_append(1))  # [1]
print(good_append(2))  # [2] — новый список!
print(good_append(3, [10, 20]))  # [10, 20, 3]

# Другие примеры плохих умолчаний
def bad_defaults(lst=[], dct={}, st=set()):
    lst.append(1)
    dct['key'] = 'value'
    st.add(1)
    return lst, dct, st

# Все вызовы будут использовать ОДНИ И ТЕ ЖЕ объекты!
```

## Механизм передачи аргументов

### Передача по ссылке на объект (call by object reference)
В Python аргументы передаются по **ссылке на объект**. Это означает, что функция получает ссылку на тот же объект, но сама переменная не может быть изменена
```python
def demonstrate_passing(x, lst):
    print(f"ID x внутри: {id(x)}")
    print(f"ID lst внутри: {id(lst)}")
    
    x = x + 10  # создает НОВЫЙ объект
    lst.append(4)  # изменяет существующий объект
    
    print(f"ID x после изменения: {id(x)}")
    print(f"ID lst после изменения: {id(lst)}")
    
    return x, lst

a = 5
b = [1, 2, 3]
print(f"ID a до: {id(a)}")
print(f"ID b до: {id(b)}")

result_x, result_lst = demonstrate_passing(a, b)

print(f"a после: {a}")  # 5 (не изменилось!)
print(f"b после: {b}")  # [1, 2, 3, 4] (изменилось!)
```

### Неизменяемые vs изменяемые типы
```python
# НЕИЗМЕНЯЕМЫЕ ТИПЫ (int, float, str, tuple, frozenset)
def modify_immutable(x):
    print(f"Внутри до: {x}, id={id(x)}")
    x = x * 2  # создает новый объект
    print(f"Внутри после: {x}, id={id(x)}")
    return x

a = 5
print(f"Снаружи до: {a}, id={id(a)}")
modify_immutable(a)
print(f"Снаружи после: {a}, id={id(a)}")  # 5, тот же id

# ИЗМЕНЯЕМЫЕ ТИПЫ (list, dict, set, bytearray)
def modify_mutable(lst):
    print(f"Внутри до: {lst}, id={id(lst)}")
    lst.append(4)  # изменяет объект
    lst[0] = 99    # изменяет объект
    print(f"Внутри после: {lst}, id={id(lst)}")

b = [1, 2, 3]
print(f"Снаружи до: {b}, id={id(b)}")
modify_mutable(b)
print(f"Снаружи после: {b}, id={id(b)}")  # [99, 2, 3, 4], тот же id
```

### Присваивание параметру vs изменение объекта
```python
def confusion(lst):
    # Присваивание параметру — меняет локальную переменную
    lst = [4, 5, 6]  # lst теперь ссылается на НОВЫЙ список
    print(f"Внутри: {lst}")

def clarity(lst):
    # Изменение объекта через ссылку
    lst[:] = [4, 5, 6]  # изменяет оригинал!
    print(f"Внутри: {lst}")

original = [1, 2, 3]
confusion(original)
print(f"После confusion: {original}")  # [1, 2, 3] — не изменился!

original = [1, 2, 3]
clarity(original)
print(f"После clarity: {original}")  # [4, 5, 6] — изменился!
```

### Срез для копирования
```python
def safe_process(lst):
    # Работаем с копией, не затрагивая оригинал
    working_copy = lst[:]  # копия
    working_copy.append(4)
    working_copy[0] = 99
    return working_copy

original = [1, 2, 3]
result = safe_process(original)
print(f"Оригинал: {original}")  # [1, 2, 3] — не изменился
print(f"Результат: {result}")   # [99, 2, 3, 4]
```

## Произвольное число позиционных аргументов (*args)

### Основы *args
`*args` позволяет функции принимать произвольное количество позиционных аргументов. `args` — это кортеж
```python
def sum_all(*args):
    """Принимает любое количество чисел"""
    print(f"Тип args: {type(args)}")  # <class 'tuple'>
    print(f"Содержимое: {args}")
    return sum(args)

print(sum_all(1, 2, 3))        # 6
print(sum_all(1, 2, 3, 4, 5))  # 15
print(sum_all())               # 0 (пустой кортеж)

# Имя args — это соглашение, можно любое
def multiply(*numbers):
    result = 1
    for n in numbers:
        result *= n
    return result

print(multiply(2, 3, 4))  # 24
```

### *args в комбинации с обычными параметрами
```python
def register(username, age, *skills):
    """username и age — обязательные, skills — опциональные"""
    print(f"Пользователь: {username}, возраст: {age}")
    if skills:
        print(f"Навыки: {', '.join(skills)}")
    else:
        print("Навыков нет")

register("Анна", 25)
register("Иван", 30, "Python", "SQL", "Django")
register("Петр", 22, "JavaScript")

# Порядок важен: сначала обычные, потом *args
# def wrong(pos, *args, another):  # так нельзя! another никогда не получит значение
#     pass

def correct(pos, *args, kwd_only=None):  # *args забирает все лишние позиционные
    print(f"pos={pos}, args={args}, kwd_only={kwd_only}")

correct(1, 2, 3, 4, kwd_only=10)  # pos=1, args=(2,3,4), kwd_only=10
```

### *args для оберток и декораторов
```python
def logger(func):
    """Декоратор, логирующий вызовы любой функции"""
    def wrapper(*args, **kwargs):
        print(f"Вызов {func.__name__} с args={args}, kwargs={kwargs}")
        result = func(*args, **kwargs)
        print(f"Результат: {result}")
        return result
    return wrapper

@logger
def add(a, b):
    return a + b

@logger
def multiply(a, b, c=1):
    return a * b * c

add(5, 3)
multiply(2, 3, c=4)
```

## Произвольное число именованных аргументов (**kwargs)

### Основы **kwargs
`**kwargs` позволяет функции принимать произвольное количество именованных аргументов. `kwargs` — это словарь
```python
def print_info(**kwargs):
    """Принимает любое количество именованных аргументов"""
    print(f"Тип kwargs: {type(kwargs)}")  # <class 'dict'>
    for key, value in kwargs.items():
        print(f"{key}: {value}")

print_info(name="Анна", age=25, city="Москва")
# name: Анна
# age: 25
# city: Москва

print_info()
# (ничего не выводит)
```

### **kwargs для гибких конфигураций
```python
def create_window(title, **options):
    """Создает окно с опциями"""
    window = {"title": title}
    
    # Стандартные значения
    defaults = {
        "width": 800,
        "height": 600,
        "resizable": True,
        "bg": "white"
    }
    
    # Обновляем переданными опциями
    defaults.update(options)
    window.update(defaults)
    
    return window

print(create_window("Мое окно"))
# {'title': 'Мое окно', 'width': 800, 'height': 600, 'resizable': True, 'bg': 'white'}

print(create_window("Чат", width=1024, height=768, bg="blue", icon="chat.ico"))
# {'title': 'Чат', 'width': 1024, 'height': 768, 'resizable': True, 'bg': 'blue', 'icon': 'chat.ico'}
```

### **kwargs для передачи аргументов дальше
```python
def request(url, method="GET", **kwargs):
    """Обертка для HTTP запросов"""
    print(f"Запрос к {url} методом {method}")
    
    # Стандартные заголовки
    headers = {
        "User-Agent": "MyApp/1.0",
        "Accept": "application/json"
    }
    
    # Добавляем пользовательские заголовки, если есть
    if "headers" in kwargs:
        headers.update(kwargs.pop("headers"))
    
    # Остальные kwargs передаем в requests
    import requests
    response = requests.request(method, url, headers=headers, **kwargs)
    return response

# Использование
response = request(
    "https://api.example.com/users",
    method="POST",
    json={"name": "Анна"},
    headers={"Authorization": "Bearer token123"},
    timeout=30
)
```

## Комбинация разных типов аргументов

### Полный порядок параметров
В Python строгий порядок определения параметров:
1. **Позиционные параметры** (обычные)
2. **Параметры со значением по умолчанию**
3. **`*args`** (произвольное число позиционных)
4. **Параметры только по имени** (keyword-only)
5. **`**kwargs`** (произвольное число именованных)

```python
def complex_function(
    pos1, pos2,                # позиционные
    default1="def1",            # со значением по умолчанию
    default2="def2",            # еще один со значением по умолчанию
    *args,                      # произвольные позиционные
    kw_only1, kw_only2,         # только по имени (обязательные!)
    kw_default="kw_def",        # только по имени с умолчанием
    **kwargs                    # произвольные именованные
):
    print(f"pos: {pos1}, {pos2}")
    print(f"default: {default1}, {default2}")
    print(f"args: {args}")
    print(f"kw_only: {kw_only1}, {kw_only2}")
    print(f"kw_default: {kw_default}")
    print(f"kwargs: {kwargs}")

# Вызов
complex_function(
    1, 2,                       # pos1, pos2
    "custom1", "custom2",        # default1, default2
    3, 4, 5,                     # *args
    kw_only1="hello",            # kw_only1
    kw_only2="world",            # kw_only2
    extra1="extra",              # **kwargs
    extra2="another"             # **kwargs
)
```

### Практические примеры комбинаций
```python
# API клиент с гибкими параметрами
class APIClient:
    def __init__(self, base_url, api_key=None, timeout=30):
        self.base_url = base_url
        self.api_key = api_key
        self.timeout = timeout
    
    def request(self, method, endpoint, *args, **kwargs):
        """Универсальный метод запроса"""
        url = f"{self.base_url}{endpoint}"
        
        # Извлекаем специальные параметры
        headers = kwargs.pop('headers', {})
        params = kwargs.pop('params', {})
        
        if self.api_key:
            headers['Authorization'] = f"Bearer {self.api_key}"
        
        # Логируем запрос
        print(f"{method} {url}")
        print(f"Headers: {headers}")
        print(f"Params: {params}")
        print(f"Additional args: {args}")
        print(f"Remaining kwargs: {kwargs}")
        
        # Здесь был бы реальный запрос
        return {"status": 200, "data": ...}
    
    def get(self, endpoint, **kwargs):
        return self.request("GET", endpoint, **kwargs)
    
    def post(self, endpoint, data=None, **kwargs):
        return self.request("POST", endpoint, data=data, **kwargs)

# Использование
client = APIClient("https://api.example.com", api_key="secret")
result = client.get(
    "/users",
    params={"page": 1, "limit": 10},
    headers={"X-Custom": "value"},
    timeout=5
)
```

def wrong_order(a, b=10, *args, c):  # c никогда не получит значение!

# 3. *args после keyword-only

    pass

## Распаковка аргументов при вызове (* и **)

### Распаковка позиционных аргументов (*)
Оператор `*` распаковывает итерируемый объект в позиционные аргументы
```python
def point(x, y, z):
    print(f"x={x}, y={y}, z={z}")

# Распаковка списка
coords_list = [10, 20, 30]
point(*coords_list)  # x=10, y=20, z=30

# Распаковка кортежа
coords_tuple = (40, 50, 60)
point(*coords_tuple)  # x=40, y=50, z=60

# Распаковка строки (каждый символ)
point(*"ABC")  # x='A', y='B', z='C'

# Распаковка range
point(*range(3))  # x=0, y=1, z=2

# Распаковка генератора
point(*(x*10 for x in range(3)))  # x=0, y=10, z=20

# Количество элементов должно совпадать!
# point(*[1, 2])     # TypeError: missing 1 argument
# point(*[1, 2, 3, 4])  # TypeError: too many arguments
```

### Распаковка именованных аргументов (**)
Оператор `**` распаковывает словарь в именованные аргументы
```python
def create_profile(name, age, city):
    print(f"Name: {name}, Age: {age}, City: {city}")

# Распаковка словаря
user_data = {"name": "Анна", "age": 25, "city": "Москва"}
create_profile(**user_data)  # Name: Анна, Age: 25, City: Москва

# Ключи должны совпадать с именами параметров
wrong_data = {"username": "Анна", "age": 25, "city": "Москва"}
# create_profile(**wrong_data)  # TypeError: unexpected keyword 'username'

# Можно комбинировать с обычными аргументами
create_profile("Иван", **{"age": 30, "city": "СПб"})
# Name: Иван, Age: 30, City: СПб
```

### Комбинированная распаковка
```python
def full_function(a, b, c, d, e):
    print(f"a={a}, b={b}, c={c}, d={d}, e={e}")

# Комбинация разных источников
args_list = [1, 2]
args_dict = {"d": 4, "e": 5}
full_function(*args_list, 3, **args_dict)
# a=1, b=2, c=3, d=4, e=5

# Порядок важен: сначала позиционные, потом именованные
def demo(x, y, z):
    print(x, y, z)

data = {"y": 20, "z": 30}
demo(10, **data)  # 10 20 30
# demo(**data, 10)  # SyntaxError!
```

### Распаковка для копирования и слияния
```python
# Копирование списков
original = [1, 2, 3]
copy = [*original]  # [1, 2, 3]
print(copy is original)  # False

# Слияние списков
list1 = [1, 2]
list2 = [3, 4]
merged = [*list1, *list2, 5, 6]  # [1, 2, 3, 4, 5, 6]

# Копирование словарей (Python 3.5+)
original_dict = {"a": 1, "b": 2}
copy_dict = {**original_dict}  # {'a': 1, 'b': 2}

# Слияние словарей (с перезаписью)
dict1 = {"a": 1, "b": 2}
dict2 = {"b": 20, "c": 3}
merged_dict = {**dict1, **dict2, "d": 4}
print(merged_dict)  # {'a': 1, 'b': 20, 'c': 3, 'd': 4}

# Python 3.9+ можно через |
merged_dict_v2 = dict1 | dict2 | {"d": 4}
```

### Распаковка для функций с переменным числом аргументов
```python
def multiply(*args):
    result = 1
    for num in args:
        result *= num
    return result

numbers = [2, 3, 4]
print(multiply(*numbers))  # 24

def show_info(**kwargs):
    for key, value in kwargs.items():
        print(f"{key}: {value}")

data = {"name": "Анна", "age": 25, "city": "Москва"}
show_info(**data)
```

    "message": "User logged in",
    "user_id": 123,
    "ip": "192.168.1.1"

    return base ** exponent

## Частые вопросы и ключевые выводы

### FAQ
**В: В чем разница между `*args` и `**kwargs`?**
**О:** `*args` собирает все лишние позиционные аргументы в кортеж. `**kwargs` собирает все лишние именованные аргументы в словарь.

**В: Почему нельзя использовать изменяемые объекты как значения по умолчанию?**
**О:** Потому что они создаются один раз при определении функции и будут общими для всех вызовов. Используйте `None` и создавайте новый объект внутри функции.

**В: Что означает `/` и `*` в определении функции?**
**О:** `/` означает, что параметры слева могут быть только позиционными. `*` означает, что параметры справа могут быть только именованными.

**В: Как передать список как отдельные аргументы?**
**О:** Используйте оператор распаковки `*`: `func(*my_list)`

**В: Как передать словарь как именованные аргументы?**
**О:** Используйте оператор распаковки `**`: `func(**my_dict)`

**В: Что произойдет, если передать слишком много аргументов?**
**О:** Если функция определена с `*args`, лишние позиционные аргументы попадут в `args`. Иначе будет `TypeError`.

**В: Можно ли иметь два `*args` в одной функции?**
**О:** Нет, можно только один `*args`. Все лишние позиционные аргументы собираются в него.

**В: Что быстрее: позиционные или именованные аргументы?**
**О:** Позиционные немного быстрее, так как не требуется поиск по словарю. Разница обычно незначительна.

### Ментальная модель аргументов
```
Представьте функцию как конвейер:

Позиционные аргументы (по порядку):
[Анна] [25] [Москва] → [name] [age] [city]

Именованные аргументы (по имени):
[name=Анна] [age=25] [city=Москва] → [name] [age] [city]

*args как коробка для лишнего:
[1] [2] [3] [4] [5] → [a] [b] [*args = (3,4,5)]

**kwargs как мешок с ярлыками:
[theme=dark] [lang=ru] → [**kwargs = {'theme': 'dark', 'lang': 'ru'}]

Распаковка * и **:
[1,2,3] → * → 1,2,3
{'x':1,'y':2} → ** → x=1, y=2
```
