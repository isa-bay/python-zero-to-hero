## Установка и настройка окружения Python

### Установка Python

#### Windows
**Способ 1: Официальный установщик (рекомендуемый)**

1. **Скачивание:**
   - Перейдите на [python.org/downloads](https://www.python.org/downloads/)
   - Нажмите желтую кнопку "Download Python X.X.X" (автоматически определит вашу ОС)

2. **Установка:**
   - **Обязательно поставьте галочку** внизу: **`☑ Add Python X.X to PATH`**
   - Это позволит запускать Python из командной строки простой командой `python`
   - Выберите "Install Now" (обычная установка) или "Customize installation" (если хотите изменить путь)

3. **Проверка установки:**
   - Откройте **Командную строку** (`Win + R` → `cmd` → Enter)
   - Введите: `python --version` (должно показать версию)
   - Введите: `pip --version` (менеджер пакетов)

**Способ 2: Microsoft Store (альтернатива)**
- Откройте Microsoft Store, найдите Python
- Плюсы: автоматическое обновление, не требует прав администратора
- Минусы: версия может обновляться с задержкой

**Способ 3: Windows Package Manager (для продвинутых)**
```bash
winget install Python.Python.3.12
```

#### macOS
**Способ 1: Официальный установщик**
1. **Скачивание:**
   - Перейдите на [python.org/downloads](https://www.python.org/downloads/)
   - Скачайте установщик для macOS

2. **Установка:**
   - Запустите `.pkg` файл
   - Пройдите шаги установщика
   - Важно: установщик автоматически добавляет Python в PATH

**Способ 2: Homebrew (рекомендуемый)**
```bash
# Установка Homebrew (если нет)
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# Установка Python
brew install python

# Проверка
python3 --version
pip3 --version
```

**Важно для macOS:**
- На macOS **уже предустановлен Python 2.7** (для нужд системы)
- **НЕ УДАЛЯЙТЕ** его! Это может сломать систему
- Всегда используйте `python3` и `pip3` для работы с Python 3

#### Linux (Ubuntu/Debian-based)

**Способ 1: Из официальных репозиториев (просто, но версия может быть старой)**

```bash
# Обновление списка пакетов
sudo apt update

# Установка Python 3 и pip
sudo apt install python3 python3-pip python3-venv

# Проверка
python3 --version
pip3 --version
```

**Способ 2: deadsnakes PPA (более свежие версии)**

```bash
# Добавление репозитория deadsnakes
sudo apt update
sudo apt install software-properties-common
sudo add-apt-repository ppa:deadsnakes/ppa
sudo apt update

# Установка конкретной версии (например, 3.11)
sudo apt install python3.11 python3.11-venv python3.11-dev
```

#### Проверка установки (все ОС)

Создайте тестовый скрипт:
```bash
# Создайте файл test.py
echo "print('Hello, Python!')" > test.py

# Запустите
python test.py      # Windows
python3 test.py     # Mac/Linux
```

### Первая программа ("Hello, World!")
**Интерактивный режим (REPL):**
```python
# В терминале введите:
>>> print("Hello, World!")
Hello, World!
>>> 2 + 2
4
>>> exit()  # Выход
```

**Скриптовый режим (файл):**
```python
# hello.py
#!/usr/bin/env python3
# -*- coding: utf-8 -*-

"""
Моя первая программа на Python
Демонстрация базовых возможностей
"""

def main():
    # Вывод на экран
    print("=" * 50)
    print("Hello, World!")
    print("=" * 50)
    
    # Работа с вводом пользователя
    name = input("Как тебя зовут? ")
    print(f"Приятно познакомиться, {name}!")
    
    # Простая математика
    age = int(input("Сколько тебе лет? "))
    print(f"Через 5 лет тебе будет {age + 5}")

if __name__ == "__main__":
    main()
```

**Запуск:**
```bash
python hello.py
```

### Выбор и настройка IDE
#### PyCharm (от JetBrains) - лучший для профессиональной разработки
**Установка:**
1. Скачайте с [jetbrains.com/pycharm/download](https://www.jetbrains.com/pycharm/download/)
2. **Community Edition** - бесплатная (достаточно для изучения)
3. **Professional Edition** - платная (для веб-разработки, баз данных)

**Настройка:**
1. **Создание проекта:**
   - `New Project`
   - Выберите расположение
   - **Важно:** Настройте интерпретатор:
     - `New environment using Virtualenv`
     - Базовый интерпретатор: путь к вашему Python

2. **Ключевые настройки (File → Settings):**
   - **Editor → General → Auto Import:** `☑ Add unambiguous imports on the fly`
   - **Editor → Font:** Увеличьте размер шрифта, рекомендую 14-16
   - **Editor → Color Scheme:** Выберите тему, рекомендую Darcula для темной
   - **Tools → Python Integrated Tools:** Выберите pytest как тестовый раннер

3. **Полезные плагины:**
   - **Rainbow Brackets** - цветные скобки
   - **Key Promoter X** - учит горячим клавишам
   - **.ignore** - для .gitignore файлов

4. **Горячие клавиши (жизненно важные):**
   - `Ctrl + Shift + F10` - запуск текущего файла
   - `Shift + F10` - запуск последнего скрипта
   - `Ctrl + D` - дублировать строку
   - `Ctrl + Y` - удалить строку
   - `Ctrl + Alt + L` - отформатировать код
   - `Shift + F6` - переименовать переменную/функцию везде

#### VS Code (от Microsoft) - легкий, гибкий, бесплатный

**Установка:**
1. Скачайте с [code.visualstudio.com](https://code.visualstudio.com/)
2. Установите, обязательно поставьте галочку:
   - `☑ Add "Open with Code" action to Windows Explorer file context menu`
   - `☑ Add to PATH`

**Настройка для Python:**

1. **Установка расширений (Extensions `Ctrl+Shift+X`):**
   - **Python** - основное
   - **Pylance** - мощный анализатор кода
   - **Python Docstring Generator** - для документации
   - **Python Test Explorer** - для запуска тестов

2. **Настройка интерпретатора:**
   - `Ctrl+Shift+P` → `Python: Select Interpreter`
   - Выберите ваш Python

3. **Настройка VS Code (`Ctrl+,`):**
   - **Editor: Font Size** → 14
   - **Files: Auto Save** → `afterDelay`
   - **Python › Formatting: Provider** → `black`

4. **Создание конфигурации для запуска (launch.json):**
   ```json
   {
       "version": "0.2.0",
       "configurations": [
           {
               "name": "Python: Current File",
               "type": "python",
               "request": "launch",
               "program": "${file}",
               "console": "integratedTerminal"
           }
       ]
   }
   ```

5. **Горячие клавиши VS Code:**
   - `F5` - запуск с отладкой
   - `Ctrl + F5` - запуск без отладки
   - `Shift + Alt + F` - форматирование кода
   - `Ctrl + ` ` (бэктик) - открыть терминал

### Настройка рабочего окружения
#### Виртуальные окружения (Virtual Environments)
Зачем? Чтобы изолировать зависимости для разных проектов.

**Создание:**
```bash
# Встроенный venv (Python 3.3+)
python -m venv myproject_env

# Активация:
# Windows:
myproject_env\Scripts\activate
# Mac/Linux:
source myproject_env/bin/activate

# Деактивация:
deactivate
```

**Современный подход: pipenv (рекомендуется)**
```bash
# Установка
pip install pipenv

# Создание окружения и установка пакетов
pipenv install requests flask

# Активация
pipenv shell

# Установка из Pipfile
pipenv install
```

```bash
# Установка Git
```

### Управление версиями Python (pyenv)

**Зачем?** Нужно тестировать код на разных версиях Python или работать с проектами, требующими конкретную версию.

**Установка pyenv:**

**Mac:**
```bash
brew update
brew install pyenv

# Добавить в ~/.zshrc или ~/.bash_profile
echo 'export PYENV_ROOT="$HOME/.pyenv"' >> ~/.zshrc
echo 'export PATH="$PYENV_ROOT/bin:$PATH"' >> ~/.zshrc
echo 'eval "$(pyenv init --path)"' >> ~/.zshrc
```

**Linux:**
```bash
curl https://pyenv.run | bash

# Добавить в ~/.bashrc
export PATH="$HOME/.pyenv/bin:$PATH"
eval "$(pyenv init --path)"
eval "$(pyenv virtualenv-init -)"
```

**Windows:** Используйте [pyenv-win](https://github.com/pyenv-win/pyenv-win)

**Использование pyenv:**
```bash
# Посмотреть доступные версии
pyenv install --list

# Установить конкретную версию
pyenv install 3.9.18
pyenv install 3.11.6

# Посмотреть установленные версии
pyenv versions

# Глобальная версия по умолчанию
pyenv global 3.11.6

# Локальная версия для проекта
cd myproject
pyenv local 3.9.18  # создаст .python-version
```

### Работа в терминале

**Базовые команды (нужно знать обязательно):**

```bash
# Навигация
pwd                      # текущая директория
ls                       # список файлов (Mac/Linux)
dir                      # список файлов (Windows)
cd folder                # перейти в папку
cd ..                    # на уровень выше
cd ~                     # домой
cd -                     # в предыдущую директорию

# Работа с файлами
touch file.py            # создать файл (Mac/Linux)
echo "" > file.py        # создать файл (Windows)
cat file.py              # показать содержимое
type file.py             # показать содержимое (Windows)
cp file.py file2.py      # копировать
mv file.py new.py        # переименовать/переместить
rm file.py               # удалить файл
mkdir folder             # создать папку
rm -rf folder            # удалить папку (осторожно!)

# Python специфичные
python -c "print('hi')"  # выполнить одну команду
python -m http.server    # запустить простой HTTP сервер
python -m pdb script.py  # запустить отладчик
```

### Частые проблемы и их решение

#### Проблема 1: "Python не найдена" (команда не найдена)
**Симптомы:** `'python' is not recognized as an internal or external command`
**Решение:**
- Windows: Переустановите Python, обязательно включив "Add to PATH"
- Или добавьте в PATH вручную:
  ```powershell
  # Временное решение (для сессии)
  $env:Path += ";C:\Users\Имя\AppData\Local\Programs\Python\Python311\"
  
  # Постоянное решение - через системные переменные
  ```

#### Проблема 2: "pip не работает"
**Симптомы:** `pip: command not found`
**Решение:**
```bash
# Установка pip
python -m ensurepip --upgrade

# Использование pip через python
python -m pip install requests

# На Windows: используйте pip3 или py -m pip
```

#### Проблема 3: "ошибка кодировки" (UnicodeEncodeError)
**Симптомы:** Ошибки при печати русских букв в Windows
**Решение:**
```python
# В начале скрипта
import sys
import io
sys.stdout = io.TextIOWrapper(sys.stdout.buffer, encoding='utf-8')
```

#### Проблема 4: "конфликт версий Python"
**Симптомы:** Используется Python 2 вместо Python 3
**Решение:**
- Всегда используйте `python3` на Mac/Linux
- На Windows проверьте порядок в PATH (Python 3 должен быть выше)

#### Проблема 5: "ошибка прав доступа" (Permission denied)
**Симптомы:** Невозможно установить пакет глобально
**Решение:**
```bash
# Используйте виртуальное окружение (лучший способ)
# Или установка для пользователя
pip install --user requests
```

#### Проблема 6: "SSL: CERTIFICATE_VERIFY_FAILED"
**Симптомы:** Ошибки при установке пакетов через pip
**Решение:**
```bash
# Обновление сертификатов
pip install --upgrade certifi

# В крайнем случае (небезопасно!):
pip install --trusted-host pypi.org --trusted-host files.pythonhosted.org package_name
```

- [ ] Python установлен (проверка: `python --version`)
- [ ] pip работает (проверка: `pip --version`)
- [ ] Умею создавать и запускать .py файлы
- [ ] Установлена IDE (PyCharm или VS Code)
- [ ] Настроен базовый синтаксис в IDE (подсветка, автодополнение)
- [ ] Знаю основные команды терминала (cd, ls/dir, mkdir)
- [ ] Могу установить сторонний пакет: `pip install requests`

#### Средний уровень (активный разработчик)
- [ ] Настроено виртуальное окружение для проектов
- [ ] Умею пользоваться отладчиком (breakpoints, step over/into)
- [ ] Настроен Git и .gitignore
- [ ] Установлены полезные плагины в IDE
- [ ] Знаю горячие клавиши для основных операций
- [ ] Умею работать с Jupyter Notebook (если нужно для Data Science)

- [ ] Настроен pyenv для переключения версий Python
- [ ] Использую форматтеры (black, autopep8) и линтеры (flake8, pylint)
- [ ] Настроен pre-commit hook для автоматической проверки кода
- [ ] Есть кастомные сниппеты в IDE для ускорения
- [ ] Настроена интеграция с Docker для изолированной разработки
- [ ] Автоматизирована установка окружения через Makefile или скрипты

#### Проверочный скрипт "Всё готово"

Создайте файл `check_env.py`:

```python
#!/usr/bin/env python3
"""
Скрипт проверки готовности Python-окружения
"""
import sys
import platform
import subprocess
from pathlib import Path

def check_python():
    print(f"Python версия: {sys.version}")
    print(f"Расположение: {sys.executable}")
    print(f"Платформа: {platform.system()} {platform.release()}")
    print(f"Кодировка: {sys.getfilesystemencoding()}")

def check_pip():
    try:
        import pip
        print(f"pip версия: {pip.__version__}")
    except ImportError:
        print("pip НЕ установлен!")

def check_virtual_env():
    in_venv = hasattr(sys, 'real_prefix') or (hasattr(sys, 'base_prefix') and sys.base_prefix != sys.prefix)
    print(f"В виртуальном окружении: {in_venv}")
    if in_venv:
        print(f"Путь окружения: {sys.prefix}")

def check_packages():
    required = ['requests', 'numpy', 'pytest']
    print("\nПроверка пакетов:")
    for package in required:
        try:
            __import__(package)
            print(f"✅ {package} установлен")
        except ImportError:
            print(f"❌ {package} НЕ установлен")

def check_git():
    try:
        result = subprocess.run(['git', '--version'], capture_output=True, text=True)
        print(f"Git: {result.stdout.strip()}")
    except FileNotFoundError:
        print("Git не найден")

if __name__ == "__main__":
    print("=" * 50)
    print("ПРОВЕРКА PYTHON-ОКРУЖЕНИЯ")
    print("=" * 50)
    
    check_python()
    check_pip()
    check_virtual_env()
    check_packages()
    check_git()
    
    print("=" * 50)
    print("Окружение проверено!")
```

Запустите:
```bash
python check_env.py
```
