## Что такое модуль?

### Определение
**Модуль** — это файл с расширением `.py`, содержащий определения функций, классов и переменных, а также исполняемый код. Модули являются фундаментальной единицей организации кода в Python
```python
# Простейший модуль (my_module.py)
"""
Это docstring модуля. Описывает, что делает модуль.
"""

# Константы
VERSION = "1.0.0"
AUTHOR = "Анна"

# Функции
def greet(name):
    return f"Hello, {name}!"

def add(a, b):
    return a + b

# Классы
class Calculator:
    def multiply(self, a, b):
        return a * b

# Код верхнего уровня (выполняется при импорте)
print(f"Модуль {__name__} загружен")
```

### Зачем нужны модули?
```python
# 1. Организация кода
# Вместо одного огромного файла:
#   main.py (5000 строк) → ужасно!

# Лучше разбить на модули:
#   main.py (точка входа)
#   database.py (работа с БД)
#   models.py (модели данных)
#   utils.py (вспомогательные функции)
#   config.py (конфигурация)

# 2. Повторное использование
# utils.py
def validate_email(email):
    import re
    pattern = r'^[\w\.-]+@[\w\.-]+\.\w+$'
    return re.match(pattern, email) is not None

def format_date(date, format="%Y-%m-%d"):
    return date.strftime(format)

# В любом другом файле:
# from utils import validate_email, format_date

# 3. Пространства имен (namespace)
# math.py
def sin(x):
    return "вычисление синуса"

# main.py
import math
import my_math  # наш модуль с другой реализацией sin

print(math.sin(90))     # из стандартной библиотеки
print(my_math.sin(90))  # из нашего модуля

# 4. Инкапсуляция (скрытие деталей)
# database.py
_connection = None  # "приватная" переменная (по соглашению)

def connect(url):
    global _connection
    _connection = create_connection(url)

def query(sql):
    return _connection.execute(sql)

# Пользователи модуля видят только connect и query
```

## Создание модуля

### Базовый модуль
Создайте файл `mymath.py`:
```python
# mymath.py
"""Мой математический модуль"""

__version__ = "1.0"
__author__ = "Анна"

PI = 3.14159
E = 2.71828

def add(a, b):
    """Сложение двух чисел"""
    return a + b

def subtract(a, b):
    """Вычитание двух чисел"""
    return a - b

class Circle:
    """Класс для работы с окружностями"""
    
    def __init__(self, radius):
        self.radius = radius
    
    def area(self):
        return PI * self.radius ** 2
    
    def circumference(self):
        return 2 * PI * self.radius

# Код для тестирования модуля
if __name__ == "__main__":
    # Этот код выполнится только при прямом запуске файла
    print("Тестирование модуля mymath")
    print(f"2 + 3 = {add(2, 3)}")
    c = Circle(5)
    print(f"Площадь круга: {c.area()}")
```

### Поиск модуля: пошагово
```python
# Что происходит при import mymodule

import sys
import os

def find_module(module_name):
    """Имитация поиска модуля"""
    
    # 1. Проверяем кэш
    if module_name in sys.modules:
        print(f"Найден в кэше: {sys.modules[module_name]}")
        return sys.modules[module_name]
    
    # 2. Ищем по каждому пути в sys.path
    for path in sys.path:
        # Пропускаем пустые пути
        if not path:
            path = os.getcwd()
        
        # Проверяем файл module_name.py
        py_file = os.path.join(path, f"{module_name}.py")
        if os.path.isfile(py_file):
            print(f"Найден файл: {py_file}")
            return py_file
        
        # Проверяем package/module_name/__init__.py
        pkg_dir = os.path.join(path, module_name)
        init_file = os.path.join(pkg_dir, "__init__.py")
        if os.path.isfile(init_file):
            print(f"Найден пакет: {pkg_dir}")
            return pkg_dir
    
    raise ImportError(f"No module named '{module_name}'")

# Пример
try:
    find_module("math")
except ImportError as e:
    print(e)
```

## Кэширование модулей

### sys.modules — кэш загруженных модулей
Когда модуль импортируется первый раз, он загружается и помещается в `sys.modules`. При повторном импорте используется кэшированная версия
```python
import sys

# Все загруженные модули
print("Загруженные модули:")
for name, module in list(sys.modules.items())[:5]:  # первые 5
    print(f"  {name}: {module}")

# Проверка, загружен ли модуль
if 'math' in sys.modules:
    print("math уже загружен")
else:
    import math
    print("math загружен сейчас")

# sys.modules — это словарь
print(type(sys.modules))  # <class 'dict'>

# Можно удалить модуль из кэша (редко нужно)
if 'math' in sys.modules:
    del sys.modules['math']
    # Теперь следующий import math загрузит модуль заново
```

### Механизм работы кэша
```python
# Демонстрация кэширования
import sys
import time

def measure_import(module_name):
    start = time.perf_counter()
    __import__(module_name)
    end = time.perf_counter()
    return end - start

# Первый импорт — загрузка модуля
time1 = measure_import('json')
print(f"Первый импорт json: {time1:.6f} сек")

# Второй импорт — из кэша
time2 = measure_import('json')
print(f"Второй импорт json: {time2:.6f} сек")

# Третий импорт — тоже из кэша
time3 = measure_import('json')
print(f"Третий импорт json: {time3:.6f} сек")

# Разница может быть в 10-100 раз!
```

### reload — принудительная перезагрузка
Иногда нужно перезагрузить модуль без перезапуска интерпретатора (например, в разработке)
```python
import importlib
import mymodule

# Изменяем mymodule.py в редакторе...

# Перезагрузка модуля
importlib.reload(mymodule)

# Старая версия (Python 2)
# reload(mymodule)  # встроенная функция, но не рекомендуется

# Особенности reload:
# - Перезагружает только указанный модуль, не его зависимости

# - Не всегда безопасно (может привести к несоответствиям)

```

### Импорт и кэширование в деталях
```python
# Что происходит при первом импорте

import sys
import types

def simulate_import(module_name):
    """Имитация процесса импорта"""
    
    # 1. Проверка кэша
    if module_name in sys.modules:
        print(f"Модуль {module_name} уже в кэше")
        return sys.modules[module_name]
    
    print(f"Модуль {module_name} не найден в кэше")
    
    # 2. Поиск модуля (find_module)
    print(f"Поиск модуля {module_name}...")
    
    # 3. Создание объекта модуля
    module = types.ModuleType(module_name)
    
    # 4. Добавление в кэш ДО выполнения кода
    sys.modules[module_name] = module
    print(f"Модуль добавлен в кэш")
    
    # 5. Выполнение кода модуля
    print(f"Выполнение кода модуля {module_name}")
    # здесь выполняется код из файла
    
    return module

# Почему модуль добавляется в кэш до выполнения?
# Чтобы обработать рекурсивные импорты внутри модуля
```

## Практические примеры и паттерны

### Создание исполняемого модуля
```python
#!/usr/bin/env python3
# calculator.py

"""
Калькулятор с интерфейсом командной строки.
Использование: python calculator.py 2 + 3
"""

import sys
import operator

# Словарь операций
OPERATIONS = {
    '+': operator.add,
    '-': operator.sub,
    '*': operator.mul,
    '/': operator.truediv,
    '//': operator.floordiv,
    '%': operator.mod,
    '**': operator.pow,
}

def calculate(expression):
    """Вычисляет выражение вида '2 + 3'"""
    if len(expression) != 3:
        raise ValueError("Нужно 3 аргумента: число оператор число")
    
    try:
        a = float(expression[0])
        b = float(expression[2])
        op = expression[1]
    except (ValueError, IndexError):
        raise ValueError("Некорректные аргументы")
    
    if op not in OPERATIONS:
        raise ValueError(f"Неизвестная операция: {op}")
    
    return OPERATIONS[op](a, b)

def main():
    """Точка входа для командной строки"""
    if len(sys.argv) != 4:
        print(__doc__)
        sys.exit(1)
    
    try:
        result = calculate(sys.argv[1:])
        print(f"Результат: {result}")
    except Exception as e:
        print(f"Ошибка: {e}")
        sys.exit(1)

if __name__ == "__main__":
    main()
```

### Модуль с ленивой загрузкой зависимостей
```python
# analysis.py
"""
Модуль для анализа данных с опциональными зависимостями.
"""

import importlib

class DataAnalyzer:
    """Анализатор данных с ленивой загрузкой библиотек"""
    
    def __init__(self, data):
        self.data = data
        self._numpy = None
        self._pandas = None
        self._matplotlib = None
    
    @property
    def np(self):
        """Ленивая загрузка numpy"""
        if self._numpy is None:
            try:
                self._numpy = importlib.import_module('numpy')
            except ImportError:
                raise ImportError("NumPy не установлен. Установите: pip install numpy")
        return self._numpy
    
    @property
    def pd(self):
        """Ленивая загрузка pandas"""
        if self._pandas is None:
            try:
                self._pandas = importlib.import_module('pandas')
            except ImportError:
                raise ImportError("Pandas не установлен. Установите: pip install pandas")
        return self._pandas
    
    def mean(self):
        """Среднее значение с numpy"""
        return self.np.mean(self.data)
    
    def to_dataframe(self):
        """Преобразование в pandas DataFrame"""
        return self.pd.DataFrame(self.data)
```

```python
# config.py
"""
Модуль управления конфигурацией.
Загружает настройки из разных источников.
"""

import os
import json
import yaml
from pathlib import Path

class Config:
    """Класс для управления конфигурацией"""
    
    DEFAULT_CONFIG = {
        'debug': False,
        'host': 'localhost',
        'port': 8080,
        'database': {
            'url': 'sqlite:///app.db',
            'pool_size': 5,
        }
    }
    
    def __init__(self):
        self._config = self.DEFAULT_CONFIG.copy()
        self._loaded_files = []
    
    def load_from_file(self, filename):
        """Загружает конфигурацию из файла"""
        path = Path(filename)
        if not path.exists():
            raise FileNotFoundError(f"Файл {filename} не найден")
        
        suffix = path.suffix.lower()
        with open(path) as f:
            if suffix == '.json':
                data = json.load(f)
            elif suffix in ('.yml', '.yaml'):
                data = yaml.safe_load(f)
            else:
                raise ValueError(f"Неподдерживаемый формат: {suffix}")
        
        self._update_recursive(self._config, data)
        self._loaded_files.append(str(path))
    
    def _update_recursive(self, target, source):
        """Рекурсивное обновление словаря"""
        for key, value in source.items():
            if key in target and isinstance(target[key], dict) and isinstance(value, dict):
                self._update_recursive(target[key], value)
            else:
                target[key] = value
    
    def load_from_env(self, prefix='APP_'):
        """Загружает конфигурацию из переменных окружения"""
        for key, value in os.environ.items():
            if key.startswith(prefix):
                config_key = key[len(prefix):].lower()
                self._set_nested(self._config, config_key.split('__'), value)
    
    def _set_nested(self, config, keys, value):
        """Устанавливает значение во вложенном словаре"""
        for key in keys[:-1]:
            if key not in config:
                config[key] = {}
            config = config[key]
        config[keys[-1]] = value
    
    def get(self, key, default=None):
        """Получает значение по ключу (поддерживает точечную нотацию)"""
        keys = key.split('.')
        value = self._config
        for k in keys:
            if isinstance(value, dict):
                value = value.get(k)
                if value is None:
                    return default
            else:
                return default
        return value
    
    def __getitem__(self, key):
        return self.get(key)
    
    def __repr__(self):
        return f"Config(loaded_files={self._loaded_files})"

# Создаем синглтон
config = Config()
```

### Модуль для работы с базой данных
```python
# database.py
"""
Модуль для работы с базой данных.
Предоставляет единый интерфейс для разных БД.
"""

import sqlite3
from contextlib import contextmanager
from typing import Optional, Any

class DatabaseError(Exception):
    """Базовое исключение для ошибок БД"""
    pass

class ConnectionError(DatabaseError):
    """Ошибка подключения к БД"""
    pass

class QueryError(DatabaseError):
    """Ошибка выполнения запроса"""
    pass

class Database:
    """Абстракция для работы с БД"""
    
    def __init__(self, db_url: str):
        self.db_url = db_url
        self._connection = None
    
    def connect(self):
        """Устанавливает соединение с БД"""
        try:
            if self.db_url.startswith('sqlite://'):
                db_path = self.db_url[9:]
                self._connection = sqlite3.connect(
                    db_path,
                    detect_types=sqlite3.PARSE_DECLTYPES
                )
                self._connection.row_factory = sqlite3.Row
            else:
                # Здесь могла бы быть поддержка PostgreSQL, MySQL и т.д.
                raise ConnectionError(f"Неподдерживаемый тип БД: {self.db_url}")
        except Exception as e:
            raise ConnectionError(f"Не удалось подключиться к БД: {e}")
    
    def disconnect(self):
        """Закрывает соединение с БД"""
        if self._connection:
            self._connection.close()
            self._connection = None
    
    @contextmanager
    def transaction(self):
        """Контекстный менеджер для транзакций"""
        if not self._connection:
            self.connect()
        
        cursor = self._connection.cursor()
        try:
            yield cursor
            self._connection.commit()
        except Exception:
            self._connection.rollback()
            raise
        finally:
            cursor.close()
    
    def execute(self, query: str, params: tuple = ()) -> list:
        """Выполняет запрос и возвращает результаты"""
        if not self._connection:
            self.connect()
        
        try:
            cursor = self._connection.cursor()
            cursor.execute(query, params)
            results = [dict(row) for row in cursor.fetchall()]
            cursor.close()
            return results
        except Exception as e:
            raise QueryError(f"Ошибка выполнения запроса: {e}")
    
    def __enter__(self):
        self.connect()
        return self
    
    def __exit__(self, *args):
        self.disconnect()

# Создаем экземпляр для использования в других модулях
db = Database("sqlite:///app.db")
```

## Частые вопросы и ключевые выводы

### FAQ
**В: В чем разница между модулем и пакетом?**
**О:** Модуль — это один файл `.py`. Пакет — это директория с модулями и файлом `__init__.py`.

**В: Где Python ищет модули?**
**О:** В директориях из `sys.path`: текущая директория, PYTHONPATH, стандартные пути, site-packages.

**В: Что такое `__name__ == "__main__"`?**
**О:** Проверка, запущен ли файл напрямую (а не импортирован). Используется для тестов и CLI.

**В: Почему повторный импорт быстрее?**
**О:** Модули кэшируются в `sys.modules`. При повторном импорте используется кэшированная версия.

**В: Что такое циклический импорт и как его избежать?**
**О:** Когда модуль A импортирует B, а B импортирует A. Избегайте через импорт внутри функций, рефакторинг, или отложенный импорт.

**В: Когда использовать `from module import *`?**
**О:** Практически никогда. Это загрязняет пространство имен и делает код непонятным.

**В: Как создать исполняемый скрипт на Python?**
**О:** Добавьте shebang `#!/usr/bin/env python3` и проверку `if __name__ == "__main__":`.

### Ментальная модель модулей
```
Представьте модули как книги в библиотеке:

sys.path — каталог библиотеки (где искать книги)
sys.modules — книги, которые вы уже взяли (кэш)
__name__ — название книги
__main__ — книга, которую вы сейчас читаете

Процесс импорта:
1. Посмотреть, нет ли книги уже на руках (sys.modules)
2. Если нет — найти в каталоге (sys.path)
3. Прочитать книгу (выполнить код)
4. Положить на полку прочитанных (sys.modules)

Пакет — это серия книг в одной папке
__init__.py — оглавление серии
```
