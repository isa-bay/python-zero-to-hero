## Работа со строками (str)

### Что такое строки в Python?
**Строка (`str`)** — это неизменяемая (`immutable`) последовательность символов Unicode. В Python 3 строки полностью основаны на стандарте Unicode, что делает их идеальными для работы с текстом на любых языках
```python
# Строка — это последовательность
s = "hello"
print(len(s))           # 5
print(s[0])             # 'h'
print(s[-1])            # 'o'

# Строка неизменяема
s = "hello"
# s[0] = 'H'  # TypeError: 'str' object does not support item assignment

# Любая операция создает НОВУЮ строку
s2 = s.upper()
print(s)   # "hello" (оригинал не изменился)
print(s2)  # "HELLO" (новая строка)
```

### Внутреннее устройство строк в CPython
В CPython строки хранятся в одной из трех форм, в зависимости от содержимого:
```python
import sys

# 1. Compact ASCII (1 байт на символ) — только латиница, цифры, базовая пунктуация
ascii_str = "hello world 123"
print(f"ASCII строка: {sys.getsizeof(ascii_str)} байт")

# 2. Compact (1, 2 или 4 байта на символ) — Unicode с кодами до 0xFFFF
unicode_str = "привет мир"
print(f"Unicode строка (кириллица): {sys.getsizeof(unicode_str)} байт")

# 3. Legacy — для обратной совместимости (редко)

# Демонстрация разных форматов хранения
a = "a" * 1000  # все символы ASCII
b = "я" * 1000  # все символы Unicode (кириллица)

print(f"1000 ASCII символов: {sys.getsizeof(a)} байт")    # ~1000 + overhead
print(f"1000 Unicode символов: {sys.getsizeof(b)} байт")  # ~2000 + overhead (т.к. 2 байта на символ)
```

### Интернирование строк (String Interning)
Python автоматически интернирует (кэширует) некоторые строки для экономии памяти и ускорения сравнений:
```python
# Короткие строки, похожие на идентификаторы, интернируются
a = "hello"
b = "hello"
print(a is b)  # True (один объект!)

# Строки с пробелами или спецсимволами — обычно нет
c = "hello world"
d = "hello world"
print(c is d)  # False (разные объекты)
print(c == d)  # True (но значения равны)

# Явное интернирование
import sys
e = sys.intern("hello world" * 100)
f = sys.intern("hello world" * 100)
print(e is f)  # True (теперь интернированы)

# Когда это полезно: при работе с множеством повторяющихся строк
# Например, при парсинге большого XML с повторяющимися тегами
```

### Основные операции со строками
#### Конкатенация (объединение)
```python
# Оператор +
s1 = "Hello"
s2 = "World"
result = s1 + " " + s2  # "Hello World"

# ПРОБЛЕМА: конкатенация в цикле
def bad_concat(n):
    """Создает N новых строк! O(n²) по памяти и времени"""
    s = ""
    for i in range(n):
        s += str(i)  # На каждой итерации создается новая строка!
    return s

# РЕШЕНИЕ: использовать join
def good_concat(n):
    """Создает только одну строку в конце"""
    parts = []
    for i in range(n):
        parts.append(str(i))
    return "".join(parts)

# ИЛИ генератор
def best_concat(n):
    return "".join(str(i) for i in range(n))

# Сравнение производительности
import timeit
n = 10000
print(timeit.timeit(lambda: bad_concat(n), number=10))   # ~0.5 сек
print(timeit.timeit(lambda: good_concat(n), number=10))  # ~0.01 сек
```

#### Повторение строк
```python
# Оператор *
s = "Ha"
print(s * 3)      # "HaHaHa"
print(3 * s)      # "HaHaHa" (коммутативно)

# Полезно для создания разделителей
separator = "-" * 50
print(separator)

# Создание строк фиксированной длины
def pad_left(text, width, char=" "):
    return char * (width - len(text)) + text

print(pad_left("42", 5, "0"))  # "00042"
```

#### Индексация и срезы (slicing)
```python
s = "Hello, World!"

# Индексация
print(s[0])      # 'H' (первый)
print(s[7])      # 'W' (восьмой)
print(s[-1])     # '!' (последний)
print(s[-5])     # 'o' (пятый с конца)

# Срезы [start:stop:step]
print(s[0:5])    # "Hello" (от 0 до 4 включительно)
print(s[7:12])   # "World" (от 7 до 11)
print(s[:5])     # "Hello" (от начала)
print(s[7:])     # "World!" (до конца)
print(s[:])      # копия всей строки

# Шаг
print(s[::2])    # "Hlo ol!" (каждый второй)
print(s[1::2])   # "el,Wrd" (каждый второй, начиная с 1)
print(s[::-1])   # "!dlroW ,olleH" (реверс строки)

# Срезы с отрицательным шагом
print(s[5:0:-1])  # ",olle" (от 5 до 1 в обратном порядке)
print(s[-1::-1])  # "!dlroW ,olleH" (реверс)

# Важно: срезы создают НОВЫЕ строки
s2 = s[:5]
print(id(s), id(s2))  # разные id
```

### Форматирование строк
В Python есть 4 основных способа форматирования строк. Каждый имеет свои особенности:

#### 1. %-форматирование (старый стиль)
```python
# Cтиль printf из C (работает, но не рекомендуется для нового кода)
name = "Анна"
age = 25
height = 1.75

# Базовое использование
s = "Имя: %s, возраст: %d" % (name, age)
print(s)  # "Имя: Анна, возраст: 25"

# Словарь для именованных параметров
s = "Имя: %(name)s, возраст: %(age)d" % {"name": name, "age": age}

# Форматирование чисел
print("Шестнадцатеричное: %x" % 255)      # "ff"
print("С плавающей точкой: %.2f" % 3.14159)  # "3.14"
print("С шириной поля: %10s" % "hello")    # "     hello"
print("Выравнивание: %-10s" % "hello")     # "hello     "

# Недостатки:
# - Ограниченные возможности
# - Сложно читать при многих параметрах
# - TypeError при несоответствии типов
```

#### 2. str.format() (Python 2.6+)
```python
# Более мощный и гибкий метод
name = "Анна"
age = 25
height = 1.75

# Позиционные аргументы
s = "Имя: {}, возраст: {}".format(name, age)
print(s)  # "Имя: Анна, возраст: 25"

# Индексы для повторного использования
s = "{0} {1} {0}".format("один", "два")  # "один два один"

# Именованные аргументы
s = "Имя: {name}, возраст: {age}".format(name=name, age=age)

# Смешанное использование
s = "{0} {name} {1}".format(1, 2, name=name)

# Форматирование чисел
print("{:10}".format(42))           # "        42" (ширина 10)
print("{:<10}".format(42))          # "42        " (влево)
print("{:>10}".format(42))          # "        42" (вправо)
print("{:^10}".format(42))          # "    42    " (по центру)
print("{:*^10}".format(42))         # "****42****" (заполнитель)
print("{:010}".format(42))          # "0000000042" (нули слева)
print("{:+d}".format(42))           # "+42" (знак)
print("{:-d}".format(42))           # "42" (знак только для отрицательных)
print("{: d}".format(42))           # " 42" (пробел для положительных)

# Дроби и проценты
print("{:.2f}".format(3.14159))     # "3.14"
print("{:.0f}".format(3.14159))     # "3"
print("{:,.2f}".format(1234567.89)) # "1,234,567.89" (разделители тысяч)
print("{:.2%}".format(0.256))       # "25.60%" (проценты)

# Системы счисления
print("{:b}".format(42))            # "101010" (двоичная)
print("{:o}".format(42))            # "52" (восьмеричная)
print("{:x}".format(42))            # "2a" (16-чная, нижний)
print("{:X}".format(42))            # "2A" (16-чная, верхний)

# Доступ к атрибутам и элементам
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

p = Point(10, 20)
print("Точка: {0.x}, {0.y}".format(p))  # "Точка: 10, 20"

data = {'name': 'Анна', 'age': 25}
print("Имя: {0[name]}, возраст: {0[age]}".format(data))

# Выравнивание текста
text = "Hello"
print("{:>20}".format(text))  # "               Hello"
print("{:_^20}".format(text)) # "_______Hello________"
```

#### 3. f-strings (форматированные строки, Python 3.6+)
Современный и предпочтительный способ, самый читаемый и быстрый
```python
name = "Анна"
age = 25
height = 1.75

# Базовое использование
s = f"Имя: {name}, возраст: {age}"
print(s)

# Выражения внутри {}
print(f"2 + 2 = {2 + 2}")
print(f"Имя в верхнем регистре: {name.upper()}")
print(f"Квадрат числа: {age ** 2}")

# Вызов методов
print(f"Длина имени: {len(name)}")

# Форматирование чисел (как в format)
print(f"Число π: {3.14159:.2f}")
print(f"Число с шириной: {42:10}")
print(f"Выравнивание: {name:>20}")
print(f"Проценты: {0.256:.2%}")

# Многострочные f-strings
message = (
    f"Имя пользователя: {name}\n"
    f"Возраст: {age}\n"
    f"Рост: {height:.2f}м"
)
print(message)

# Словари и атрибуты
user = {"name": "Анна", "age": 25}
print(f"Имя: {user['name']}, возраст: {user['age']}")

# Дата и время
from datetime import datetime
now = datetime.now()
print(f"Сейчас: {now:%Y-%m-%d %H:%M}")

# Вложенные f-strings (Python 3.8+)
width = 10
precision = 2
value = 3.14159
print(f"Результат: {value:{width}.{precision}f}")

# Отладка (Python 3.8+)
x = 42
print(f"{x = }")      # "x = 42"
print(f"{x + 1 = }")  # "x + 1 = 43"

# Производительность f-strings
import timeit

def test_fstring():
    name = "Анна"
    age = 25
    return f"Имя: {name}, возраст: {age}"

def test_format():
    name = "Анна"
    age = 25
    return "Имя: {}, возраст: {}".format(name, age)

def test_percent():
    name = "Анна"
    age = 25
    return "Имя: %s, возраст: %d" % (name, age)

print("f-string:", timeit.timeit(test_fstring, number=10**6))
print("format:", timeit.timeit(test_format, number=10**6))
print("%:", timeit.timeit(test_percent, number=10**6))
# f-strings обычно самые быстрые
```

#### 4. Template strings (для безопасного форматирования)
```python
from string import Template

# Полезно, когда строки приходят от пользователя (безопаснее)
t = Template("Имя: $name, возраст: $age")
s = t.substitute(name="Анна", age=25)
print(s)  # "Имя: Анна, возраст: 25"

# Если переменной нет - KeyError
# t.substitute(name="Анна")  # KeyError: 'age'

# safe_substitute не бросает исключение
s = t.safe_substitute(name="Анна")
print(s)  # "Имя: Анна, возраст: $age"

# Двойные знаки $ для экранирования
t = Template("$$${name}")  # $${name} -> $ + ${name}
print(t.substitute(name="X"))  # "$X"
```

#### Сравнение методов форматирования

| Метод | Гибкость | Скорость | Читаемость | Безопасность | Когда использовать |
|-------|----------|----------|------------|--------------|-------------------|
| `%` | Низкая | Средняя | Низкая | Низкая | Legacy код |
| `str.format()` | Высокая | Средняя | Средняя | Средняя | Сложное форматирование |
| **f-strings** | Высокая | **Высокая** | **Высокая** | Высокая | **90% случаев** |
| `Template` | Низкая | Низкая | Средняя | **Высокая** | Пользовательский ввод |

### Классификация методов строк
Строки в Python имеют около 50 встроенных методов. Разделим их на категории:

#### 1. Изменение регистра
```python
s = "Hello, World!"

print(s.upper())              # "HELLO, WORLD!"
print(s.lower())              # "hello, world!"
print(s.capitalize())          # "Hello, world!" (первая заглавная)
print(s.title())              # "Hello, World!" (каждое слово с заглавной)
print(s.swapcase())           # "hELLO, wORLD!" (меняет регистр)

# Для однострочного текста
print(s.casefold())           # "hello, world!" (более агрессивный lower, для сравнения)

# Проверка регистра
print("HELLO".isupper())      # True
print("hello".islower())      # True
print("Hello World".istitle()) # True
```

#### 2. Поиск и замена
```python
s = "Hello, World! Hello, Python!"

# Поиск подстроки
print(s.find("Hello"))        # 0 (первое вхождение)
print(s.find("hello"))        # -1 (не найдено)
print(s.rfind("Hello"))       # 14 (последнее вхождение)
print(s.index("World"))       # 7 (как find, но ValueError если нет)
print(s.rindex("Hello"))      # 14

# Поиск с ограничением
print(s.find("Hello", 10))    # 14 (ищем после 10-й позиции)

# Подсчет вхождений
print(s.count("Hello"))       # 2
print(s.count("l"))           # 7

# Замена
print(s.replace("Hello", "Hi"))        # "Hi, World! Hi, Python!"
print(s.replace("Hello", "Hi", 1))     # "Hi, World! Hello, Python!" (только первое)

# Трансляция символов (продвинутая замена)
trans = str.maketrans("Helo", "1234")
print(s.translate(trans))     # "1234, Wor1d! 1234, Pyt4n!"
```

#### 3. Проверки (is* методы)
```python
# Проверка содержимого
print("42".isdigit())          # True (только цифры)
print("42".isdecimal())        # True (десятичные цифры)
print("42".isnumeric())        # True (числовые символы, включая римские и др.)

# Разница между isdigit, isdecimal, isnumeric
print("²".isdigit())           # True (надстрочный символ - цифра)
print("²".isdecimal())         # False (не десятичная цифра)
print("²".isnumeric())         # True (числовой символ)

print("⅕".isdigit())           # False
print("⅕".isdecimal())         # False
print("⅕".isnumeric())         # True (дробь - число)

# Буквы и цифры
print("abc123".isalnum())      # True (буквы + цифры)
print("abc123!".isalnum())     # False (! не буква и не цифра)

# Только буквы
print("abc".isalpha())         # True
print("abc123".isalpha())      # False

# Пробельные символы
print("   ".isspace())         # True
print("\t\n".isspace())        # True

# ASCII-проверка
print("hello".isascii())       # True
print("привет".isascii())      # False

# Проверка печатных символов
print("hello".isprintable())   # True
print("hello\n".isprintable()) # False (\n непечатаемый)

# Регистр
print("ABC".isupper())         # True
print("abc".islower())         # True
print("Hello World".istitle()) # True
```

#### 4. Разделение и объединение
```python
# split - разделение на список
s = "apple,banana,orange"
print(s.split(","))           # ['apple', 'banana', 'orange']

s = "один два три четыре"
print(s.split())              # ['один', 'два', 'три', 'четыре'] (по пробелам)
print(s.split(maxsplit=2))    # ['один', 'два', 'три четыре']

# rsplit - разделение справа
print(s.rsplit(maxsplit=2))   # ['один два', 'три', 'четыре']

# splitlines - разделение по линиям
text = "первая\nвторая\nтретья"
print(text.splitlines())      # ['первая', 'вторая', 'третья']
print(text.splitlines(True))  # ['первая\n', 'вторая\n', 'третья'] (с保留)

# partition - разделение на три части
s = "username:password"
print(s.partition(":"))       # ('username', ':', 'password')
print(s.rpartition(":"))      # то же, но с конца

# join - объединение (важно!)
words = ['Hello', 'World', 'Python']
print(" ".join(words))        # "Hello World Python"
print("-".join(words))        # "Hello-World-Python"
print("".join(words))         # "HelloWorldPython"

# join с генератором (эффективно)
result = "".join(str(i) for i in range(10))
print(result)                 # "0123456789"
```

#### 5. Удаление пробелов и символов
```python
s = "  \tHello World!  \n"

# Удаление конкретных символов

# До Python 3.9 приходилось делать так:
print(s[5:] if s.startswith("Hello") else s)  # "World"
```

#### 6. Выравнивание и заполнение
```python
s = "Hello"

# Выравнивание
print(s.center(11))           # "   Hello   "
print(s.ljust(10))            # "Hello     "
print(s.rjust(10))            # "     Hello"

# С заполнителем
print(s.center(11, "*"))      # "***Hello***"
print(s.ljust(10, "-"))       # "Hello-----"
print(s.rjust(10, "."))       # ".....Hello"

# zfill - заполнение нулями слева (для чисел)
```

#### Нормализация Unicode
Одна и та же буква может быть представлена разными способами:
```python
import unicodedata

# Комбинированные символы
e_accent1 = 'é'           # предварительно составленный символ
e_accent2 = 'e\u0301'     # 'e' + комбинирующий акцент

print(e_accent1)          # "é"
print(e_accent2)          # "é" (визуально похоже)
print(e_accent1 == e_accent2)  # False! Разные представления

# Нормализация
norm1 = unicodedata.normalize('NFC', e_accent2)   # составная форма
norm2 = unicodedata.normalize('NFD', e_accent1)   # декомпозированная

print(norm1 == e_accent1)  # True (после NFC)
print(len(e_accent1))      # 1
print(len(e_accent2))      # 2 ('e' + акцент)
print(len(norm2))          # 2 (декомпозированная)

# Формы нормализации:
# NFC - составная форма (используйте для хранения/отображения)
# NFD - декомпозированная (для сравнения/поиска)
# NFKC/NFKD - совместимая нормализация (более агрессивная)

text = "ﬁ"  # лигатура "fi"
print(len(text))                    # 1
print(len(unicodedata.normalize('NFKC', text)))  # 2 ("f" + "i")
```
